# 01. Перцептрон с нуля

Первый ML-проект курса. Без `ndarray`, без Candle, без `rand` — только Rust и математика.

## Запуск

```bash
cd ~/rust-learning
cargo run -p perceptron
cargo test -p perceptron
```

## Что внутри

Один нейрон:

```text
z = w1*x1 + w2*x2 + b
ŷ = 1, если z >= 0, иначе 0
```

Обучение:

```text
error = y - ŷ
w_i += learning_rate * error * x_i
b   += learning_rate * error
```

Датасеты OR и AND линейно разделимы, поэтому один перцептрон их решает. XOR — нет; для него нужен скрытый слой (lab09).

## Задания

1. Поменяй `learning_rate` (0.01, 0.1, 1.0) и число эпох. Что происходит?
2. Попробуй обучить на XOR. Объясни, почему accuracy не 1.0.
3. Добавь третий признак и датасет, который зависит от трёх входов.
4. Сделай `accuracy` возвращающей `Option<f64>` (`None` для пустого набора) вместо `0.0`.
5. Реализуй `train` с остановкой по `max_errors` или по норме изменения весов.
6. Нарисуй разделяющую прямую для OR на бумаге: `w1*x1 + w2*x2 + b = 0`.
