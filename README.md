# Курс Rust с нуля до junior (ML-трек)

Учебный проект: один человек учит Rust с нуля. Всё, что нужно для занятий, лежит в этой папке.

---

## Как устроен курс

### Одна лекция = одна папка

```text
course/07-structs/
├── lecture.md     ← конспект (20–30 минут чтения)
├── quiz.md        ← короткий тест, ответы под <details>
└── lab.md         ← задание к этой лекции
```

28 папок от `01-first-program` до `28-inference-pyo3`, плюс четыре общих файла:

| Файл | Что внутри |
|---|---|
| `course/README.md` | карта лекций и правила курса |
| `course/GLOSSARY.md` | словарь терминов в порядке появления |
| `course/FORWARD-REFERENCES.md` | реестр мест, где конструкция объяснена «на месте» и полностью позже |
| `course/CHECKLIST.md` | 40 пунктов самопроверки и 30 вопросов мок-собеседования |
| `course/BUDGET.md` | языковой бюджет каждой лабы: что можно использовать на лекции N |

### Лабы — это готовые крейты, а не текст

Код лабы уже создан в `practice/`. Создавать проект и копировать код не нужно:

```bash
cd ~/rust-learning
cargo test -p l02-text      # сейчас красные: стоят todo!()
```

Внутри `practice/l02-text/src/lib.rs` лежат:
- сигнатуры функций с `todo!()` — заглушка, которая компилируется, но падает при вызове;
- готовые тесты, которые надо позеленить.

Пока `todo!()` на месте, тесты падают с `not yet implemented`. Это и есть задача.

**Почему `cargo test --workspace` красный:** в workspace есть недоделанные лабы. Это нормально —
гоняй тесты по конкретному пакету: `cargo test -p <пакет>`.

### Порядок работы над лекцией

1. Прочитать `lecture.md`. Код набирать руками, а не читать глазами.
2. Пройти `quiz.md`, не подглядывая.
3. Открыть `practice/lNN-…/src/lib.rs`, заменить `todo!()` на реализацию.
4. `cargo test -p <пакет>` — пока не позеленеет.
5. `cargo clippy -p <пакет> --all-targets -- -D warnings` и `cargo fmt -p <пакет>`.
6. Записать в `NOTES.md`, что было непонятно и какие ошибки поймал.

Последний пункт не формальность: через месяц ты не вспомнишь, почему `&` не даёт менять данные.

**Одна лаба тяжёлая.** `l27-candle` собирает Candle (LLVM, tokenizers, gemm) — несколько минут
и все ядра. Перед ней закрой лишнее и собирай так:

```bash
RAYON_NUM_THREADS=1 cargo test -j 1 -p l27-candle
```

## Правила курса

1. **Ни одно слово не используется раньше, чем объяснено.** В начале каждой лекции — список новых
   терминов с определениями.
2. **Каждый блок кода разобран построчно.** Не «вот пример», а «вот эта часть значит то».
3. **Никаких «так надо».** Если что-то странно — объяснена причина.
4. **Забегания вперёд объясняются на месте** и выписаны в `FORWARD-REFERENCES.md`.
5. **Все тексты ошибок скопированы из настоящего `rustc`**, а не написаны по памяти.

## Сколько это занимает

- лекции + тесты: ~45 минут на лекцию → **~21 час**;
- лабы: ~30 минут на лекцию → **~14 часов**;
- 4 проекта + капстоун: **~40 часов**;
- чтение чужого кода и повторение: **~30 часов**.

Итого **100–120 часов**. При 5–8 часах в неделю — несколько месяцев.

Честно: 28 лекций дают **языковой минимум** и практику, но junior-разработчиком делает не курс,
а написанные и отлаженные проекты. Чеклист готовности — в [`course/CHECKLIST.md`](course/CHECKLIST.md).

## Что где лежит

```text
rust-learning/
├── README.md              ← ты здесь
├── AGENTS.md              ← контекст для ИИ-агентов
├── HANDOFF.md             ← полная история проекта и принятых решений
├── NOTES.md               ← журнал обучения (заполняет студент)
├── Cargo.toml             ← workspace: все лабы из practice/
├── course/                ← лекции, тесты, лабы, словарь, чеклист
├── practice/              ← крейты лаб: 28 штук, заготовки с todo!() и тестами
│   ├── l01-hello/ … l28-inference/
└── .scratch/              ← служебное: эталонные решения лаб (в .gitignore)
```

`.scratch/verify/` — мои проверенные решения лаб. Нужны для поддержки курса: если правишь лабу,
сверяйся с ними. Студенту туда смотреть не обязательно (это спойлеры).

## С чего начать

1. Открой [`course/README.md`](course/README.md) — карта и правила.
2. [Лекция 1](course/01-first-program/lecture.md) → [тест](course/01-first-program/quiz.md) → [лаба](course/01-first-program/lab.md).
3. Веди записи в [`NOTES.md`](NOTES.md).

Если что-то в лекции непонятно — это ошибка курса, а не твоя. Пиши, перепишу.
