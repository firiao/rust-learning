# guess_game

Первая законченная программа: игра «угадай число».

```bash
cd ~/rust-learning
cargo run -p guess_game
cargo test -p guess_game
```

Что демонстрирует:

- `struct` и методы;
- `loop`, `match`, `Ordering`;
- `String`, `read_line`, `parse`;
- `Option` через `let-else`;
- генератор случайных чисел без внешних зависимостей;
- unit-тесты.

Идеи для улучшения:

- ограничить число попыток;
- добавить уровни сложности (1–10, 1–100, 1–1000);
- вести статистику игр в файле;
- заменить самодельный RNG на крейт `rand`;
- сделать CLI-аргументы через `std::env::args` или `clap`.
