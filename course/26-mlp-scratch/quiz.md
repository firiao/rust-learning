# Тест к лекции 26

Ответы — в конце, под `<details>`.

## Вопросы

**1.** Зачем для XOR нужен скрытый слой?

a) для скорости
b) XOR не разделяется одной прямой: нужна нелинейность
c) иначе не скомпилируется

**2.** Что делает ReLU и почему у него нулевая производная для отрицательных?

a) `max(0, x)`; при отрицательном входе градиент не идёт дальше
b) `1/(1+e^-x)`
c) `x²`

**3.** Почему для «sigmoid + BCE» градиент по логиту равен `p - y`?

a) это совпадение
b) так упрощается произведение производных: сигмоида и логарифма
c) это ошибка

**4.** Почему `dh` надо посчитать **до** обновления `w2`?

a) для скорости
b) иначе градиент считается по уже изменённым весам
c) порядок не важен

**5.** Что произойдёт, если инициализировать все веса отрицательными?

a) ничего
b) все ReLU «умрут» (выход 0), градиент не потечёт, сеть не обучится
c) сеть обучится быстрее

**6.** Зачем зажимать `p` в `clamp(1e-9, 1-1e-9)`?

a) чтобы `ln(0)` не дал `-∞`
b) для красоты
c) чтобы ускорить

**7.** Почему свой генератор с seed лучше, чем «настоящая» случайность?

a) он быстрее
b) эксперимент воспроизводим: тот же seed — тот же результат
c) иначе не скомпилируется

## Ответы

<details>
<summary>Показать</summary>

**1 — b.** Один нейрон рисует прямую; XOR не разделяется прямой.

**2 — a.** ReLU — `max(0, x)`: для отрицательных выход 0, производная 0.

**3 — b.** `d/dz BCE(σ(z), y) = σ(z) - y`.

**4 — b.** Порядок важен: сначала читаем старые веса для градиента, потом обновляем.

**5 — b.** Все активации 0 → все градиенты 0 → ничего не учится.

**6 — a.** `ln(0)` — минус бесконечность, loss станет `NaN`.

**7 — b.** Воспроизводимость важнее «случайности».
