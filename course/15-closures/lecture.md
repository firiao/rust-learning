# Лекция 15. Замыкания

**Время:** ~25 минут

**Нужно знать заранее:** функции, итераторы (`map`, `filter`), `impl Trait` из лекции 12.

**Новые слова в этой лекции:**
- **замыкание** — функция без имени, которую можно передать как значение;
- **захват** — замыкание «запоминает» переменные из окружающего кода;
- **`move`** — заставить замыкание **владеть** захваченными данными;
- **`Fn`, `FnMut`, `FnOnce`** — три трейта, описывающие, как замыкание можно вызывать;
- **`impl Fn(...) -> ...`** — как записать «принимаю замыкание».

---

## 1. Функции — не единственный способ описать действие

Обычная функция объявляется по имени и не может «запомнить» ничего из окружения:

```rust
fn add_one(x: i32) -> i32 {
    x + 1
}
```

А что если действие зависит от переменной, которая известна только в месте вызова?

```rust
fn main() {
    let limit = 10;
    // хочется «оставить только числа больше limit» — но limit не виден функции сверху
    let big: Vec<i32> = vec![1, 5, 10, 15].into_iter().filter(|n| n > &limit).collect();
    println!("{:?}", big);   // [15]
}
```

Вот `|n| n > &limit` — это **замыкание**. Оно «захватило» переменную `limit` из `main`.

---

## 2. Синтаксис

```rust
let add_one = |x: i32| x + 1;
println!("{}", add_one(5));     // 6
```

Разберём:

- `|x: i32|` — параметры в **вертикальных чертах** вместо скобок. Можно без типа: `|x|`;
- `x + 1` — тело. Как и у функции, последнее выражение без `;` — результат;
- `add_one` — переменная, в которой лежит замыкание. В Rust почти всё можно хранить в переменной, включая действие.

Замыкание с несколькими параметрами:

```rust
let add = |a: i32, b: i32| a + b;
println!("{}", add(2, 3));      // 5
```

Тело из нескольких строк — в фигурных скобках:

```rust
let clamp = |x: i32| {
    if x < 0 { 0 } else { x }
};
println!("{}", clamp(-5));      // 0
```

---

## 3. Захват: замыкание помнит окружение

Главное отличие от обычной функции:

```rust
fn main() {
    let greeting = String::from("Привет");
    let say = || println!("{greeting}");

    say();      // Привет
    say();      // Привет
}
```

Замыкание `|| ...` (без параметров) **захватило** `greeting` и может его использовать, хотя это локальная переменная `main`.

Обычная `fn` так не умеет: у неё нет доступа к локальным переменным вызывающего.

---

## 4. `move` — «забери себе»

Иногда нужно, чтобы замыкание **владело** захваченным, а не ссылалось на него:

```rust
fn main() {
    let greeting = String::from("Привет");
    let say = move || println!("{greeting}");

    say();
}
```

`move` перед вертикальными чертами переносит `greeting` внутрь замыкания (владение, лекция 5). После этого `greeting` снаружи недоступен.

Зачем это нужно: если замыкание будет жить дольше функции, ссылаться на локальные данные нельзя (лекция 6). `move` решает проблему — забрал и живёт.

Понадобится в лекции 18, когда замыкание отправляют в поток.

---

## 5. Три способа вызывать: `Fn`, `FnMut`, `FnOnce`

Это трейты (лекция 11), и они описывают, что замыкание делает с захваченным:

| Трейт | Что значит | Аналогия с методами |
|---|---|---|
| `Fn` | только читает захваченное, можно вызывать много раз | `&self` |
| `FnMut` | меняет захваченное, можно вызывать много раз | `&mut self` |
| `FnOnce` | забирает владение, можно вызвать **один раз** | `self` |

Пример `FnMut` — счётчик:

```rust
fn main() {
    let mut count = 0;
    let mut increment = || {
        count += 1;
        println!("{count}");
    };

    increment();    // 1
    increment();    // 2
}
```

Компилятор сам решает, какой из трёх трейтов реализует твоё замыкание. Тебе это важно знать, когда замыкание передают в функцию — там указывают нужный трейт.

---

## 6. Замыкание как параметр

Самое частое применение — передать «что делать» в функцию:

```rust
fn apply_twice<F: Fn(i32) -> i32>(f: F, x: i32) -> i32 {
    f(f(x))
}

fn main() {
    println!("{}", apply_twice(|n| n + 1, 5));      // 7
    println!("{}", apply_twice(|n| n * n, 3));      // 81
}
```

Разберём `fn apply_twice<F: Fn(i32) -> i32>(f: F, x: i32)`:

- `<F: Fn(i32) -> i32>` — параметр типа `F` (обобщение, лекция 12), который обязан быть вызываемым: «принимает `i32`, возвращает `i32`»;
- `f: F` — параметр `f` этого типа;
- `f(f(x))` — вызвать дважды.

Можно короче, через `impl Trait` из лекции 12:

```rust
fn apply_twice(f: impl Fn(i32) -> i32, x: i32) -> i32 {
    f(f(x))
}
```

То же самое, читается легче.

### Почему `Fn`, а не `fn`

`fn(i32) -> i32` — это **указатель на функцию** (только именованные функции). `Fn(i32) -> i32` — «любое вызываемое», включая замыкания с захватом. Первое — частный случай второго.

## 7. Замыкание как результат

```rust
fn make_adder(n: i32) -> impl Fn(i32) -> i32 {
    move |x| x + n
}

fn main() {
    let add5 = make_adder(5);
    println!("{}", add5(10));       // 15
}
```

Здесь `move` обязателен: замыкание возвращается наружу, а `n` — локальный параметр функции. Без `move` замыкание ссылалось бы на `n`, который умрёт при выходе из `make_adder`.

`impl Fn(i32) -> i32` — «какой-то тип, который вызывается так». Конкретный тип замыкания у компилятора есть, но имени у него нет, поэтому пишут `impl`.

## 8. Замыкания в итераторах

Мы уже пользовались ими в лекции 14, теперь понятно, что это было:

```rust
let numbers = vec![1, 2, 3, 4, 5, 6];

let result: Vec<i32> = numbers
    .iter()
    .filter(|&&n| n % 2 == 0)
    .map(|&n| n * n)
    .collect();
```

`|&&n| n % 2 == 0` — замыкание, которое захватывает **ничего**, поэтому работает как обычный предикат. Компилятор разрешает ему быть `Fn`.

А вот это замыкание уже захватывает переменную:

```rust
let threshold = 10;
let big: Vec<i32> = numbers.iter().filter(|&&n| n > threshold).copied().collect();
```

`.copied()` — «превратить `&i32` в `i32`» (копия). Итераторы мы разбирали в лекции 14.

## 9. Типичные ошибки

### Замыкание меняет захваченное, а переменная не `mut`

```rust
let count = 0;
let mut inc = || count += 1;
```

```text
error[E0596]: cannot borrow `count` as mutable, as it is not declared as mutable
```

Нужно `let mut count = 0;`.

### Замыкание живёт дольше захваченного

```rust
fn make() -> impl Fn() {
    let s = String::from("привет");
    || println!("{s}")           // ошибка: s умрёт
}
```

```text
error[E0373]: closure may outlive the current function, but it borrows `s`
help: to force the closure to take ownership ... use the `move` keyword
```

Компилятор прямо говорит: добавь `move`.

### Передали функцию вместо замыкания

```text
error[E0308]: mismatched types
expected a closure that implements the `Fn` trait, but this closure only implements `FnMut`
```

Значит, внутри замыкания есть изменение захваченного, а требуют `Fn`. Либо убери изменение, либо принимай `FnMut`.

---

## 10. Что ты теперь знаешь

- Замыкание — функция без имени: `|x| x + 1`.
- Захватывает переменные окружения; `move` заставляет владеть ими.
- `Fn` — читает, `FnMut` — меняет, `FnOnce` — забирает.
- Параметр-замыкание: `impl Fn(i32) -> i32`.
- Возврат замыкания: `-> impl Fn(...)` + `move`.
- В итераторах (`map`, `filter`, `fold`) замыкания — основной инструмент.
