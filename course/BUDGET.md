# Языковой бюджет лаб

Правило: **лаба N использует только то, что объяснено в лекциях 1…N.** Если в лабе нужно что-то
из будущего — это ошибка курса, а не задача студента.

| Лаба | Можно использовать | Нельзя (появится позже) |
|---:|---|---|
| 1 | `fn`, `main`, `println!`, комментарии | всё остальное |
| 2 | `let`, `mut`, типы (`i32`,`f64`,`bool`,`char`,`&str`), арифметика, сравнения, `{}`/`{:?}` нет, `.len()`, `.chars().count()`, `.to_uppercase()`, `format!` | `if`, циклы, `Vec`, `Option` |
| 3 | всё из 1–2 + параметры, `->`, `return`, блок как выражение | `if`, циклы, коллекции |
| 4 | всё из 1–3 + `if/else`, `while`, `loop`, `for`, диапазоны, массив `[T; N]`, `&&`/`\|\|`/`!` | `Vec`, `Option`, `match` |
| 5 | всё из 1–4 + `String` (`push_str`, `push`), `move`, `clone`, `Copy`, `String::from` | `Vec`, `Option`, ссылки |
| 6 | всё из 1–5 + `&`, `&mut`, срезы `&[T]`, `&text[..i]`, `char_indices` | `Vec`, `Option`, `match` |
| 7 | всё из 1–6 + `struct`, `impl`, `&self`/`&mut self`/`self`, `Self`, `derive` | `Vec`, `Option`, `match` |
| 8 | всё из 1–7 + `match`, шаблоны, `_`, guard | `Option`, `Vec` |
| 9 | всё из 1–8 + `enum`, `Option`, `if let`, `unwrap_or` | `Vec` (только срезы/массивы) |
| 10 | всё из 1–9 + `Result`, `?`, `panic!`, `Display`, `Error` | `Vec` |
| 11 | всё из 1–10 + трейты, `dyn`, `Box<dyn>` | — |
| 12 | всё из 1–11 + обобщения, `impl Trait`, `where` | — |
| 13 | всё из 1–12 + `Vec`, `HashMap`, `entry`, `use` | замыкания в цепочках (только `for`) |
| 14 | всё из 1–13 + итераторы, `collect`, `sum`, `fold`, простые замыкания | `move`-замыкания |
| 15 | всё из 1–14 + `Fn`/`FnMut`/`move` | — |
| 16 | всё из 1–15 + `mod`, `pub`, `use`, тесты, `clippy` | — |
| 17 | всё из 1–16 + `Box`, `Rc`, `RefCell`, `'static`, метки времени жизни | — |
| 18 | всё из 1–17 + потоки, `mpsc`, `Arc`, `Mutex`, `Send`/`Sync` | — |
| 19 | всё из 1–18 + features, профили, `dbg!` | — |
| 20 | всё из 1–19 + `serde`, JSON | — |
| 21 | всё из 1–20 + `clap` | — |
| 22 | всё из 1–21 + `anyhow`, `thiserror` | — |
| 23 | всё из 1–22 + `macro_rules!`, `unsafe` | — |
| 24 | всё из 1–23 + `async`, `tokio` | — |
| 25 | всё из 1–24 + `ndarray` | — |
| 26 | всё из 1–25 (MLP руками) | — |
| 27 | всё из 1–26 + `candle` | — |
| 28 | всё из 1–27 + softmax/argmax/json | — |
