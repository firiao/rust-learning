## Что делает каждая функция и зачем она нужна

Ниже у каждой функции написано **что она возвращает** и **чему она учит**. Если описание расходится
с тем, что от тебя ждут, — это ошибка курса, пиши.

### 1. `first_word(text: &str) -> &str` — вернуть **первое слово**

Вход `"привет мир"` → выход `"привет"`. Слово кончается на первом пробеле. Если пробелов нет —
вся строка. Пустая строка → пустая.

**Чему учит:** функция возвращает **срез входной строки**, а не новую строку. Никакого копирования:
тот же участок памяти, только «окно» в него.

**Где это объяснено:** лекция 6, раздел **7.5 «Возвращаем срез: первое слово»**. Там разобран
ровно этот пример и метод `char_indices()`, который даёт пары `(байтовый индекс, символ)`.

> Почему без `char_indices` не обойтись: `&text[..i]` режет **байты**. Для кириллицы индекс
> в символах даст неверный разрез и панику `not a char boundary`. `char_indices` всегда даёт
> индексы на границах символов.

### 2. `push_bang(text: &mut String)` — дописать `!` **на месте**

**Чему учит:** это зеркало `append_bang` из лабы 5. Там функция забирала `String` и возвращала
его обратно:

```rust
fn append_bang(mut text: String) -> String { ... }   // владение уехало и вернулось
```

Здесь владение **не уезжает вообще**:

```rust
fn push_bang(text: &mut String) { ... }              // поработали и вернули как было
```

Сравни вызовы:

```rust
let mut a = String::from("x");
a = append_bang(a);      // присваивание обязательно
push_bang(&mut a);       // a уже наш, присваивать нечего
```

Вот в чём связь с лекцией: `&mut` — это «одолжи с правом изменения», и это единственный способ
поменять чужую строку, не забирая её.

### 3. `sum_slice(values: &[i32]) -> i32` — сумма готового среза

**Срез создавать не надо.** Его создаёт вызывающий:

```rust
let array = [1, 2, 3];
sum_slice(&array);        // &[i32; 3] превращается в &[i32]
sum_slice(&array[0..2]);  // срез из двух элементов
```

**Чему учит:** функция умеет принимать **любой** срез — от массива, от части массива. Это работает
потому, что `&[T]` — ссылка на последовательность, а не на конкретный массив.

### 4. `count_char(text: &str, target: char) -> usize` — сколько раз символ встречается

**Чему учит:** цикл по `chars()` (символы, а не байты) и сравнение с `target`.

## Подсказки

<details>
<summary>`first_word` — если не читал раздел 7.5</summary>

```rust
for (i, ch) in text.char_indices() {
    if ch == ' ' {
        return &text[..i];   // срез от начала до пробела
    }
}
text                          // пробела нет — вся строка
```

`char_indices()` возвращает пары: байтовый индекс символа и сам символ.

</details>

<details>
<summary>`push_bang`</summary>

```rust
text.push('!');
```

`text` уже `&mut String` — менять можно напрямую, разыменование не нужно.

</details>

<details>
<summary>`sum_slice`</summary>

```rust
let mut total = 0;
for v in values {
    total += *v;      // v: &i32, поэтому *v
}
total
```

`for v in values` по срезу даёт **ссылки** на элементы. `*v` — разыменование, раздел 3.5 лекции 6.

</details>

<details>
<summary>`count_char`</summary>

```rust
let mut count = 0;
for ch in text.chars() {
    if ch == target {
        count += 1;
    }
}
count
```

</details>

<details>
<summary>Эксперименты</summary>

**1:** `E0502` — `cannot borrow 's' as mutable because it is also borrowed as immutable`.
Пока жив `&`, `&mut` не выдают.

**2:** `E0499` — два `&mut` одновременно.

**3:** `E0596` — `&mut` у переменной, объявленной без `mut`.

</details>

<details>
<summary>`count_words` — как проверить себя</summary>

Разумная сигнатура — `fn count_words(text: &str) -> usize`: строка нужна только для чтения,
забирать её незачем, считать можно по `split_whitespace()` (метод из лекции 2).

Плохой вариант — `fn count_words(text: String) -> usize`: вызывающий теряет строку, и ему придётся
делать `clone()`.

</details>
