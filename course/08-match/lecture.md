# Лекция 8. `match`: сопоставление со случаями

**Время:** ~25 минут

**Нужно знать заранее:** `if`/`else`, `bool`, числа, строки, функции, `->`, выражения.

**Новые слова в этой лекции:**
- **`match`** — конструкция «сопоставь значение с набором случаев»;
- **рукав (arm)** — одна пара «шаблон `=>` что делать» внутри `match`;
- **шаблон (pattern)** — описание, с чем сравниваем: конкретное число, строка, диапазон, кортеж;
- **`_`** — шаблон «любой остальной случай»;
- **исчерпывающесть** — требование покрыть в `match` все возможные значения.

---

## 1. Задача

В лекции 4 мы выбирали между вариантами через `if`/`else if`/`else`:

```rust
fn main() {
    let n = 2;

    let label = if n == 0 {
        "ноль"
    } else if n == 1 {
        "один"
    } else if n == 2 {
        "два"
    } else {
        "много"
    };

    println!("{label}");
}
```

Работает, но читать неудобно: одно и то же `n ==` повторяется в каждой ветке. Чем больше вариантов, тем больше шума.

Для «сравни с набором вариантов» в Rust есть отдельная конструкция — **`match`**.

```rust
fn main() {
    let n = 2;

    let label = match n {
        0 => "ноль",
        1 => "один",
        2 => "два",
        _ => "много",
    };

    println!("{label}");
}
```

Тот же смысл, но без повторяющегося `n ==`.

---

## 2. Как читается `match`

```rust
match значение {
    шаблон => что_сделать,
    шаблон => что_сделать,
    _ => что_сделать,
}
```

Разберём на примере:

```rust
fn main() {
    let n = 2;

    match n {
        0 => println!("ноль"),
        1 => println!("один"),
        2 => println!("два"),
        _ => println!("много"),
    }
}
```

```text
два
```

Что происходит по шагам:

1. `match n` — «возьми значение `n` и сопоставь с тем, что ниже»;
2. `0 => println!("ноль")` — **рукав**: «если `n` равно 0 — выполни это»;
3. проверка идёт **сверху вниз**, срабатывает **первый** подошедший рукав;
4. `_ => ...` — «любой остальной случай». `_` (подчёркивание) означает «значение не важно»;
5. `,` после рукава обязательна (кроме последнего — там можно, но стиль требует ставить).

`n = 2` не подошло к 0 и 1, подошло к 2 — напечаталось «два». Дальше не проверяется, даже если бы подошло и к `_`.

---

## 3. `match` — выражение, он даёт значение

Как и `if`, `match` возвращает значение. Поэтому его можно присвоить:

```rust
fn main() {
    let n = 95;

    let verdict = match n {
        90..=100 => "отлично",
        60..=89 => "нормально",
        _ => "плохо",
    };

    println!("{verdict}");   // отлично
}
```

Здесь `match` стоит справа от `=`, то есть работает как выражение — ровно как `if` из лекции 4. Каждый рукав даёт значение **одного и того же типа**. Если рукав — `println!(...)` (который возвращает `()`), то и весь `match` даёт `()`, и присвоить его осмысленной переменной нельзя.

Правило: **все рукава одного `match` должны давать значения одного типа**.

---

## 4. Исчерпывающесть: почему нужен `_`

Компилятор требует, чтобы `match` покрывал **все** возможные значения. Это называется **исчерпывающесть**.

Для `i32` возможных значений 4 миллиарда — перечислить невозможно. Поэтому нужен `_`: он говорит «все остальные». Без него:

```rust
match n {
    0 => "ноль",
    1 => "один",
}
```

```text
error[E0004]: non-exhaustive patterns: `i32::MIN..=-1_i32` and `2_i32..=i32::MAX` not covered
```

`non-exhaustive patterns` — «шаблоны покрывают не всё». Компилятор прямо перечисляет, какие значения остались без обработки: все отрицательные (`i32::MIN..=-1`) и все от 2 до максимума.

`i32::MIN` и `i32::MAX` — самое маленькое и самое большое число типа `i32`. Запись `i32::MIN` — это «взять константу `MIN` внутри типа `i32`» (то же двойное двоеточие, что `String::from`).

Зачем так строго: если завтра у значения появится новый вариант, компилятор заставит тебя его обработать. Забыть невозможно.

В лекции 9 будет `enum` — там исчерпывающесть становится особенно полезной: вариантов мало, и их можно перечислить все.

## 5. Шаблоны: не только числа

Шаблон — это не только «равно числу». Их несколько видов.

### Диапазоны

```rust
let score = 88;

let grade = match score {
    90..=100 => "отлично",
    75..=89 => "хорошо",
    60..=74 => "удовлетворительно",
    _ => "неуд",
};

println!("{grade}");   // хорошо
```

`90..=100` — диапазон «от 90 до 100 включительно» (та же запись, что в `for` из лекции 4).

**Важно:** диапазоны в `match` не могут пересекаться в непредсказуемом порядке — проверка идёт сверху вниз, поэтому порядок рукавов имеет значение. Переставь `60..=74` выше `75..=89` — ничего не сломается (они не пересекаются), но если написать `0..=100` первым, остальные рукава станут недостижимыми.

### Строки

```rust
let name = "Боря";

let greeting = match name {
    "Аня" => "привет, Аня",
    "Боря" => "привет, Боря",
    _ => "привет, незнакомец",
};

println!("{greeting}");   // привет, Боря
```

### Логические значения

```rust
match is_ready {
    true => println!("готов"),
    false => println!("не готов"),
}
```

Здесь `_` не нужен: `bool` имеет ровно два значения, и оба перечислены. Компилятор доволен.

### Кортежи: несколько значений сразу

```rust
let x = 3;
let y = 3;

let where_is_it = match (x, y) {
    (0, 0) => "начало координат",
    (0, _) => "на оси Y",
    (_, 0) => "на оси X",
    (a, b) if a == b => "на диагонали",
    _ => "обычная точка",
};

println!("{where_is_it}");   // на диагонали
```

`(x, y)` — кортеж из двух значений (кортеж мы видели в лекции 2: это набор значений разных типов в круглых скобках). В шаблоне можно указать конкретные значения и `_` для «любое», а также дать имена (`a`, `b`) — они доступны в правой части рукава.

### Условие в рукаве (guard)

```rust
(a, b) if a == b => "на диагонали",
```

`if a == b` после шаблона — дополнительное условие. Читается: «если шаблон подошёл **и** условие истинно».

## 6. Что `match` даёт по сравнению с `if`

| | `if` / `else if` | `match` |
|---|---|---|
| сравнение с числом | `if n == 0` | `0 =>` |
| сравнение с диапазоном | `if (0..=9).contains(&n)` | `0..=9 =>` |
| несколько значений сразу | нужно писать `x == 0 && y == 0` | `(0, 0) =>` |
| проверка «всё покрыто» | нет | **обязательна** |
| читаемость при 5+ вариантах | плохая | хорошая |

`if` остаётся для простых условий («если температура больше 20»), `match` — для выбора из набора вариантов.

## 7. Типичные ошибки

### Забыл `_`

```text
error[E0004]: non-exhaustive patterns: `i32::MIN..=-1_i32` and `2_i32..=i32::MAX` not covered
```

Добавь `_ => ...` или перечисли остальные значения.

### Рукава разного типа

```rust
let x = match n {
    0 => 1,
    _ => "много",
};
```

```text
error[E0308]: `match` arms have incompatible types
```

Все рукава обязаны давать один тип.

### Забыл запятую между рукавами

```rust
match n {
    0 => println!("ноль")
    1 => println!("один")
    _ => println!("много")
}
```

```text
error: expected `,` or `}` found `1`
```

После рукава нужна `,` (у последнего она необязательна).

---

## 8. Что ты теперь знаешь

- `match` сравнивает значение с набором **шаблонов**, проверяя сверху вниз.
- Срабатывает **первый** подошедший рукав.
- `_` — «любой остальной случай».
- `match` — выражение; все рукава дают значения одного типа.
- Шаблоны бывают: конкретные значения, диапазоны, строки, кортежи, `_`.
- Условие в рукаве: `шаблон if условие =>`.
- Компилятор требует **исчерпывающести**.
