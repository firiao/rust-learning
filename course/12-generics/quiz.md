# Тест к лекции 12

Ответы — в конце, под `<details>`.

## Вопросы

**1.** Что означает `<T: PartialOrd + Copy>`?

a) параметр типа `T`, который умеет сравниваться и копироваться
b) два параметра: `PartialOrd` и `Copy`
c) `T` — это `PartialOrd`

**2.** Почему без ограничения `PartialOrd` сравнение `v > best` не компилируется?

a) `>` работает только с числами
b) компилятор не знает, умеет ли `T` сравниваться, и требует доказательства
c) нужно `unsafe`

**3.** Что такое мономорфизация?

a) стирание типов, как в Java
b) создание отдельной версии обобщённой функции для каждого конкретного типа
c) проверка типов во время выполнения

**4.** Чем `impl Trait` в параметре отличается от `dyn Trait`?

a) ничем
b) `impl Trait` — обобщение с одним скрытым конкретным типом; `dyn` — тип решается в рантайме
c) `impl Trait` работает только с числами

**5.** Зачем нужен `where`?

a) для ускорения
b) чтобы вынести ограничения после сигнатуры, когда их много
c) это замена `<T>`

**6.** Почему `Pair<i32>` и `Pair<&str>` — разные типы?

a) они одинаковые
b) параметр типа подставляется: получаются два разных конкретных типа
c) `Pair` может быть только один

**7.** Что будет, если в `fn f<T>(x: T) -> T { x.clone() }` нет ограничения `Clone`?

a) скомпилируется
b) `error: no method named clone found for type parameter T` + подсказка добавить `T: Clone`
c) `clone` вызовется в рантайме

**8.** Почему `Option<T>` — обобщённый тип?

a) потому что в нём может быть любое значение: `T` — параметр типа
b) потому что он из стандартной библиотеки
c) потому что он может быть `None`

---

## Ответы

<details>
<summary>Показать</summary>

**1 — a.** `:` вводит ограничение, `+` — «и ещё».

**2 — b.** Обобщённый код может делать с `T` только то, что разрешено ограничениями. Компилятор
проверяет это заранее и подсказывает нужное ограничение.

**3 — b.** Для каждого конкретного типа создаётся своя машинная версия. Цена — размер бинарника,
выигрыш — скорость без indirection.

**4 — b.** `impl Shape` в параметре — сахар для `<T: Shape>`. В возвращаемом типе `impl Trait` —
«один скрытый конкретный тип».

**5 — b.** То же, что ограничения в `<...>`, но читабельнее при трёх и более.

**6 — b.** `Pair<i32>` и `Pair<&str>` — два разных типа с одинаковой структурой.

**7 — b.** Без ограничения `T` не известно, что он умеет `clone`.

**8 — a.** `enum Option<T> { Some(T), None }` — параметр типа делает его обобщённым.

</details>
