# Лекция 2. Значения, переменные и типы

**Время:** ~25 минут

**Нужно знать заранее:** [лекцию 1](../01-first-program/lecture.md) — что такое `main`, `println!`, точка с запятой.

**Новые слова в этой лекции:**
- **переменная** — имя, за которым сохранено значение;
- **`let`** — слово, которым создают переменную;
- **тип** — вид значения: какие операции с ним допустимы и сколько он занимает памяти;
- **`mut`** — пометка «эту переменную можно менять»;
- **`i32`, `i64`, `u8`, `f64`** — названия числовых типов;
- **`bool`** — тип «истина или ложь»;
- **`char`** — один символ;
- **строка** — текст; в этой лекции — неизменяемый текстовый литерал;
- **`&str`** — тип текста; значок `&` означает «ссылка», то есть значение, которое **смотрит** на чужие данные и не владеет ими (полностью — лекция 6);
- **`format!`** — макрос, который собирает строку из частей;
- **переполнение** — ситуация, когда число не влезает в свой тип.

---

## 1. Переменная: имя для значения

В лекции 1 программа просто печатала текст. Теперь нужно **запоминать** значения, чтобы использовать их несколько раз.

Для этого есть **переменная** — имя, за которым сохранено значение.

```rust
fn main() {
    let x = 5;
    println!("{x}");
}
```

```text
5
```

Разберём строку `let x = 5;` по частям:

- **`let`** — слово, которое создаёт переменную. Читается как «пусть будет»;
- **`x`** — имя, которое ты придумал сам. Правила: буквы, цифры, подчёркивание, начинается не с цифры. Стиль Rust — `snake_case`: строчные буквы, слова через `_`;
- **`=`** — «присвоить». Справа — значение, слева — имя;
- **`5`** — значение;
- **`;`** — конец команды.

`println!("{x}")` — фигурные скобки с именем внутри означают «подставь сюда значение переменной `x`». Это подстановка, а не текст: если бы там было `println!("x")`, программа напечатала бы букву `x`, а не число 5.

## 2. `mut`: разрешение менять

Попробуем изменить переменную:

```rust
fn main() {
    let x = 5;
    x = 6;
}
```

```text
error[E0384]: cannot assign twice to immutable variable `x`
 --> main.rs:3:5
  |
2 |     let x = 5;
  |         - first assignment to `x`
3 |     x = 6;
  |     ^^^^^ cannot assign twice to immutable variable
  |
help: consider making this binding mutable
  |
2 |     let mut x = 5;
  |         +++
```

Компилятор говорит: переменную `x` нельзя менять второй раз. `immutable` значит «неизменяемая».

Это **отличие от Python и Java**: там переменные по умолчанию изменяемые, а в Rust — нет. По умолчанию значение заблокировано.

Чтобы разрешить изменения, добавляют слово **`mut`** (сокращение от *mutable*, «изменяемый»):

```rust
fn main() {
    let mut x = 5;
    x = 6;
    x = x + 1;
    println!("{x}");   // 7
}
```

Почему так сделано: когда переменную нельзя менять, её проще понимать. Читая функцию, ты знаешь, что значение не «уедет» в середине. Rust требует явно сказать «да, я собираюсь менять» — и это ловит кучу ошибок.

Правило на будущее: **`mut` ставят только там, где действительно нужно менять**. Лишний `mut` компилятор тоже заметит и предупредит: `variable does not need to be mutable`.

## 3. Что такое тип

**Тип** — это вид значения. Он отвечает на два вопроса:

1. Какие операции с этим значением допустимы? (Числа можно складывать, текст — нет.)
2. Сколько памяти оно занимает?

Rust — язык со **статическими типами**: тип каждого значения известен до запуска программы, и компилятор его проверяет. Python проверяет типы во время работы (или не проверяет вовсе), Java — тоже статическая, но с оговорками.

Тип можно указать явно:

```rust
fn main() {
    let x: i32 = 5;
    println!("{x}");
}
```

Двоеточие после имени — «эта переменная типа...». Чаще тип **не пишут**: компилятор выводит его сам из значения.

```rust
let x = 5;        // компилятор понял: i32
let y: i64 = 5;   // а здесь ты сказал явно: i64
```

Аннотировать нужно, когда компилятор не может догадаться, или когда тебе нужен конкретный тип.

## 4. Числа

Целые числа бывают разного размера. Размер определяет, какой диапазон значений влезает.

| Тип | Размер | Диапазон | Когда нужен |
|---|---|---|---|
| `i8` | 1 байт | −128 … 127 | редко |
| `i32` | 4 байта | ≈ ±2,1 млрд | **по умолчанию** |
| `i64` | 8 байт | ≈ ±9,2·10¹⁸ | большие числа |
| `u8` | 1 байт | 0 … 255 | байты, цвета |
| `u32` | 4 байта | 0 … 4,3 млрд | счётчики |
| `u64` | 8 байт | 0 … 1,8·10¹⁹ | очень большие счётчики |
| `usize` | размер указателя | 0 … очень много | индексы и размеры |
| `f32` | 4 байта | дробные | редко |
| `f64` | 8 байт | дробные | **по умолчанию** |

Буква `i` — от *integer* («целое»), `u` — от *unsigned* («беззнаковое», без минуса), `f` — от *float* («плавающее»). Цифра — размер в битах.

Значит `i32` = целое со знаком, 32 бита. `u8` = целое без знака, 8 бит.

```rust
fn main() {
    let count = 10;        // i32 (по умолчанию)
    let price = 19.99;     // f64 (по умолчанию)
    let byte: u8 = 255;
    println!("{count} {price} {byte}");
}
```

### Целочисленное деление

Главная ловушка для тех, кто знает Python:

```rust
fn main() {
    println!("{}", 9 / 5);      // 1
    println!("{}", 9.0 / 5.0);  // 1.8
}
```

Два целых числа делятся **нацело**: остаток отбрасывается. Это как `9 // 5` в Python. Чтобы получить `1.8`, хотя бы одно число должно быть дробным.

### Переполнение

`u8` вмещает 0…255. Что будет при 256?

```rust
fn main() {
    let mut byte: u8 = 255;
    byte = byte + 1;
    println!("{byte}");
}
```

В отладочной сборке (`cargo run`) программа **упадёт**:

```text
thread 'main' panicked at main.rs:3:12:
attempt to add with overflow
note: run with `RUST_BACKTRACE=1` environment variable to display a backtrace
```

**Переполнение** — ситуация, когда результат не влезает в тип. Rust в режиме отладки не «заворачивает» число в 0, а честно сообщает об ошибке. У Rust две сборки одного и того же кода:

| | `cargo run` (debug) | `cargo run --release` |
|---|---|---|
| оптимизации | выключены | включены |
| скорость работы | медленно | быстро |
| скорость сборки | быстро | медленно |
| проверки на переполнение | **включены** | выключены |

В debug-сборке компилятор вставляет проверки, чтобы ты **нашёл** ошибку у себя, а не у пользователя. В release-сборке проверки убирают ради скорости — и переполнение молча заворачивается: `255 + 1` даёт `0`.

Отсюда правило, которое спасает от классического «у меня работает, а на сервере нет»: **тестируй в debug, но проверяй и в release**, если работаешь с числами на границах типов.

## 5. `bool` — истина или ложь

```rust
fn main() {
    let is_ready = true;
    let is_empty = false;
    println!("{is_ready} {is_empty}");
}
```

Сравнения дают `bool`:

```rust
fn main() {
    let a = 5;
    let b = 3;
    println!("{}", a > b);    // true
    println!("{}", a == b);   // false
    println!("{}", a != b);   // true
}
```

Обрати внимание: **сравнение на равенство — это `==`**, два знака. Один знак `=` — это присвоение, совсем другое действие. В Python и это тоже так, а в некоторых языках — нет.

## 6. Текст: два вида

### Один символ — `char`

```rust
fn main() {
    let letter = 'a';
    let emoji = '🦀';
    println!("{letter} {emoji}");
}
```

**`char`** — ровно один символ в **одинарных** кавычках. Не больше: `'ab'` — ошибка (`character literal may only contain one codepoint`).

В лекции 1 я писал, что `'Привет'` — не строка. Теперь понятно: в одинарных кавычках Rust ждёт **один** символ.

### Строка — `"..."`

```rust
fn main() {
    let greeting = "Привет";
    println!("{greeting}");
}
```

Текст в **двойных** кавычках — это строка. Её тип называется **`&str`** (произносится «энд-стринг» или просто «стринг»).

Что здесь означает `&`: это **ссылка**. Ссылка — маленькое значение, которое указывает на другие данные, но ими не владеет. Строковый литерал `"привет"` вшивается в программу при сборке, а `&str` — это ссылка на такой текст. Поэтому:

- `&str` — **неизменяемый** текст: его нельзя дополнить или исправить;
- он существует всё время работы программы, потому что лежит в самой программе, а не создаётся в памяти.

Подробно про ссылки, `&` и `&mut` — лекция 6. Пока достаточно понимать «ссылка = смотрит на данные, но не владеет».

Позже появится второй тип строки — `String`: текст, который создаётся во время работы, живёт в памяти и **может меняться**. Он будет в лекции 5, где речь пойдёт о том, кто этой памятью управляет.

```rust
fn main() {
    let text = "привет";
    // text = "пока";   // ошибка: переменная не mut
}
```

Позже появится второй тип строки — `String`, который можно менять. Не путай их и не расстраивайся: это одно из тех мест, где Rust сначала кажется странным, а потом становится удобным.

## 7. Печать значений

В лекции 1 был `println!("Привет")` — печать готового текста. Но чаще нужно печатать **значения переменных**. Есть два способа.

**Способ 1 — фигурные скобки с именем** (современный, читаемый):

```rust
fn main() {
    let name = "Аня";
    let age = 20;
    println!("{name}, {age} лет");
}
```

```text
Аня, 20 лет
```

**Способ 2 — пустые скобки плюс аргументы** (старый, но встречается часто):

```rust
fn main() {
    let name = "Аня";
    let age = 20;
    println!("{}, {} лет", name, age);
}
```

Пустые `{}` заменяются на значения по порядку. Результат тот же.

Ещё можно вычислять прямо в подстановке:

```rust
fn main() {
    let a = 5;
    let b = 3;
    println!("{a} + {b} = {}", a + b);   // 5 + 3 = 8
}
```

### `format!` — собрать строку, не печатая

`println!` печатает. `format!` делает то же самое, но **возвращает текст**, не выводя его. Полезно, когда строку нужно собрать и потом использовать.

```rust
fn main() {
    let name = "Аня";
    let greeting = format!("Привет, {name}!");
    println!("{greeting}");
}
```

Синтаксис подстановок такой же, как у `println!`, только добавляется `=` и имя переменной, куда положить результат.

## 8. Ошибки, которые ты уже можешь встретить

### «Нельзя присвоить дважды»

```text
error[E0384]: cannot assign twice to immutable variable `x`
help: consider making this binding mutable
```

Забыл `mut`. Компилятор прямо говорит, что добавить.

### «Не совпадают типы»

```rust
fn main() {
    let x: i32 = 5.0;
}
```

```text
error[E0308]: mismatched types
  |
2 |     let x: i32 = 5.0;
  |                  ^^^ expected `i32`, found floating-point number
```

Слева целое, справа дробное. Нужно либо `5` без точки, либо тип `f64`.

### «Слишком большое число для типа»

```rust
fn main() {
    let byte: u8 = 300;
}
```

```text
error: literal out of range for `u8`
 --> main.rs:2:20
  |
2 |     let byte: u8 = 300;
  |                    ^^^
  |
  = note: the literal `300` does not fit into the type `u8` whose range is `0..=255`
```

Компилятор прямо называет допустимый диапазон: `0..=255` (запись `0..=255` значит «от 0 до 255 включительно»; про такую запись будет в лекции 4).

Там же будет предупреждение `unused variable: byte` — это отдельная история: переменная создана, но нигде не используется. На ошибку это не влияет, но компилятор о ней сообщает.

## 9. Что ты теперь знаешь

- `let имя = значение;` создаёт переменную.
- По умолчанию переменную **нельзя менять**; `let mut` разрешает.
- У каждого значения есть **тип**; обычно компилятор выводит его сам.
- `i32` и `f64` — типы по умолчанию для целых и дробных.
- `9 / 5` равно `1`; для `1.8` нужно `9.0 / 5.0`.
- `bool` — `true`/`false`; равенство проверяется через `==`.
- `'a'` — один символ (`char`), `"abc"` — строка (`&str`).
- `println!("{имя}")` и `println!("{}", имя)` печатают значение.
- `format!` собирает строку, не печатая её.
