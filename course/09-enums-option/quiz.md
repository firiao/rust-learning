# Тест к лекции 9

Ответы — в конце, под `<details>`.

## Вопросы

**1.** Чем `enum` отличается от `struct`?

a) ничем
b) значение `enum` — **одно из** вариантов; значение `struct` содержит **все** поля
c) `enum` только для чисел

**2.** Могут ли варианты одного `enum` иметь разные данные?

a) нет, только одинаковые
b) да: `Circle { radius }`, `Rectangle { width, height }`, `Empty`
c) только если это числа

**3.** Что такое `Option<T>`?

a) особая магия компилятора
b) обычное перечисление с вариантами `Some(T)` и `None`
c) аналог массива

**4.** Что нужно сделать, чтобы получить `i32` из `Option<i32>`?

a) просто присвоить
b) разобрать через `match`/`if let`/`unwrap_or`
c) ничего, типы совместимы

**5.** Что произойдёт при `None.unwrap()`?

a) вернётся 0
b) паника `called Option::unwrap() on a None value`
c) ошибка компиляции

**6.** Чем `if let` отличается от `match`?

a) ничем
b) `if let` — короткая форма для одного интересующего варианта
c) `if let` работает только с числами

**7.** Почему `#[derive(PartialEq)]` нужен, чтобы сравнить `enum` через `==`?

a) без него сравнение не скомпилируется: `PartialEq` — трейт, дающий `==`
b) это ускоряет сравнение
c) он нужен только для `struct`

**8.** Почему `match` по `Shape` не требует `_`, а по `i32` — требует?

a) `Shape` — свой тип, ему можно
b) варианты `Shape` можно перечислить все; значений `i32` — нет
c) `_` нужен всегда

---

## Ответы

<details>
<summary>Показать</summary>

**1 — b.** `struct` всегда содержит все поля. `enum` — ровно один вариант из набора.

**2 — b.** Варианты могут нести разные данные и иметь разную структуру. Это и есть «сумма типов».

**3 — b.** `enum Option<T> { Some(T), None }` — обычное перечисление из стандартной библиотеки.

**4 — b.** Тип `Option<i32>` — не `i32`. Нужно разобрать вариант.

**5 — b.** `unwrap` говорит «я уверен, что значение есть». Если ошибся — паника.

**6 — b.** `if let Some(x) = value { ... }` — это `match` с одним рукавом и пустым `_`.

**7 — a.** `==` — оператор, который работает через трейт `PartialEq`. `#[derive(PartialEq)]` генерирует
его реализацию (лекция 11 объяснит механизм).

**8 — b.** Исчерпывающесть: `match` должен покрыть все значения. Вариантов `enum` конечное число,
их перечисляют все.

</details>
