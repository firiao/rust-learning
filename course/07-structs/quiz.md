# Тест к лекции 7

Ответы — в конце, под `<details>`.

## Вопросы

**1.** Чем описание структуры отличается от экземпляра?

a) ничем
b) описание — это тип (поля и их типы), экземпляр — конкретное значение с данными
c) экземпляр создаётся компилятором

**2.** Что будет, если при создании не указать одно поле?

a) поле станет нулём
b) `error[E0063]: missing field ... in initializer`
c) поле будет `None`

**3.** Что означает `&self` в методе?

a) метод забирает владение
b) метод одалживает экземпляр только для чтения
c) метод можно вызвать без экземпляра

**4.** Чем `&mut self` отличается от `self`?

a) ничем
b) `&mut self` меняет на месте, `self` забирает владение
c) `self` только читает

**5.** Как вызвать ассоциированную функцию (без `self`)?

a) `экземпляр.функция()`
b) `Тип::функция()`
c) `функция(Тип)`

**6.** Зачем `#[derive(Debug)]`?

a) чтобы структура была публичной
b) чтобы её можно было печатать через `{:?}`
c) чтобы работало сравнение `==`

**7.** Что выведет `m.x`, где `m` — экземпляр с полем `x`?

a) ошибку компиляции
b) значение поля `x`
c) имя поля

**8.** Можно ли написать `impl Product { fn new(...) -> Self { ... } }` и вызывать `Product::new(...)`?

a) нет, `new` — зарезервированное слово
b) да, `Self` — это `Product`, а `::` — путь внутри типа
c) только если `new` помечена `pub`

**9.** Почему нельзя `#[derive(Copy)]` для структуры с полем `String`?

a) `String` слишком большой
b) `String` владеет памятью: побайтовая копия дала бы двух владельцев кучи
c) можно, ошибки не будет

---

## Ответы

<details>
<summary>Показать</summary>

**1 — b.** `struct Product { name: String, price: f64 }` — описание. `Product { name: ..., price: ... }` — экземпляр. Память выделяется при создании экземпляра.

**2 — b.** Все поля обязательны. Это гарантирует, что структура никогда не окажется «полупустой».

**3 — b.** `&self` — общее заимствование (лекция 6): читать можно, менять нельзя, владение остаётся у вызывающего.

**4 — b.** `&mut self` — право менять на месте; `self` — перемещение, после вызова переменная недоступна.

**5 — b.** `Product::new(...)`. Двойное двоеточие — путь внутри типа.

**6 — b.** `Debug` даёт `{:?}`. Без него компилятор скажет `doesn't implement Debug`.

**7 — b.** Точка — доступ к полю.

**8 — b.** `Self` — это тип, внутри которого находится `impl`.

**9 — b.** `Copy` означает «копирование битов безопасно». У `String` в куче байты: две копии указателя = два владельца = двойное освобождение. Поэтому `String` только `Clone`.

</details>
