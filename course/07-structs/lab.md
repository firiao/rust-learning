# Лаба 7. Структуры и методы

**Время:** ~20 минут
**Тема:** `struct`, `impl`, `&self`/`&mut self`, `Self`, `derive`

> **Языковой бюджет:** лекции 1–7. `Vec`, `Option` в сигнатурах и `match` не нужны.

## Цель

Две структуры с методами. Никакого кода не дано — только тесты.

## В крейте только спека

`practice/l07-structs` содержит **один файл** — `tests/spec.rs`. В `src/lib.rs` пусто.

**Тесты — это и есть ТЗ.** Из них видно:

- как называются тип и методы;
- какие у методов аргументы и что они возвращают;
- что считается правильным ответом, включая краевые случаи.

Пока кода нет, `cargo test -p l07-structs` падает **ошибками компиляции** (`cannot find type Point`).
Это нормальное состояние: спека ещё не выполнена. Как только напишешь типы — пойдут обычные
красные/зелёные тесты.

```bash
cargo test -p l07-structs
```

## Что нужно сделать

1. **Точка.** Создание из двух координат, расстояние до другой точки, сдвиг на месте.
2. **Прямоугольник.** Создание, площадь, периметр, проверка «это квадрат?», масштабирование.

Кладите в `src/lib.rs`. Ничего лишнего (например, `main`) не нужно — это библиотека.

## На что смотреть в спеке

- у каких методов нет `self` (их вызывают как `Point::new(...)`);
- где нужен `&self`, а где `&mut self` — это видно по тому, меняется ли значение;
- какие `derive` нужны, чтобы тесты скомпилировались (`assert_eq!` требует сравнения,
  `format!("{:?}")` — отладочной печати, `let copy = r;` — копирования).

## Дополнительное задание — проектируешь сам

Придумай свой тип `Money` (рубли и копейки) и метод, который переводит сумму в копейки.

**Полная свобода:** какие поля, какие типы, как назвать метод, что он принимает. Тест напиши сам
в `tests/spec.rs` рядом со спеками (свой `mod` или отдельный файл — как удобно).

В `NOTES.md` объясни, почему выбрал именно такие поля и такой `self`.

## Критерии приёмки

- [ ] 5 тестов в `tests/spec.rs` зелёные;
- [ ] `clippy -d warnings` и `fmt --check` чистые;
- [ ] в `src/lib.rs` нет ничего, кроме типов и `impl` (никакого `main`);
- [ ] в `NOTES.md` есть объяснение по `Money`.

## Подсказки

<details>
<summary>С чего начать</summary>

Прочитай первый тест в `tests/spec.rs`. Там написано что-то вроде:

```rust
let a = Point::new(0.0, 0.0);
```

Значит, нужен тип `Point` и ассоциированная функция `new`, принимающая два `f64`.

Дальше по тестам: `a.distance_to(&b)` — метод с `&self`, `p.translate(3.0, -1.0)` — с `&mut self`.
</details>

<details>
<summary>Если тест не компилируется</summary>

Ошибка `cannot find type Point` / `cannot find function new` — ты ещё не создал то, что требует тест.
Ошибка `no method named distance_to` — тип есть, метода нет.

Это не «сломалось», это спека говорит, чего не хватает.
</details>
