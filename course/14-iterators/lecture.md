# Лекция 14. Итераторы

**Время:** ~30 минут

**Нужно знать заранее:** `Vec`, `HashMap`, `for`, `Option`, методы, обобщения, замыкания ещё нет (они в лекции 15) — здесь используем только простые.

**Новые слова в этой лекции:**
- **итератор** — объект, который выдаёт элементы по одному;
- **`next()`** — метод «дай следующий элемент»; возвращает `Option`;
- **адаптер** — метод итератора, который преобразует поток (например, `map`, `filter`);
- **потребитель** — метод, который запускает работу и даёт результат (`collect`, `sum`, `count`);
- **ленивость** — адаптеры ничего не делают, пока не появится потребитель;
- **`collect`** — собрать итератор в коллекцию.

## 1. `for` уже работает через итераторы

Ты пользовался итераторами с лекции 4, просто не знал этого:

```rust
for n in &numbers {
    println!("{n}");
}
```

Внутри `for` делает примерно так: «возьми итератор у `numbers`, потом каждый раз спрашивай у него следующий элемент, пока он не скажет „больше нет"».

**Итератор** — это объект, у которого есть метод `next()`:

```rust
next() -> Option<Элемент>
```

- `Some(элемент)` — есть ещё;
- `None` — элементы кончились.

Всё остальное — удобные обёртки над этим.

## 2. Как получить итератор

Три способа, и разница — во владении (лекция 5):

| Метод | Что даёт | Что происходит с коллекцией |
|---|---|---|
| `&v` или `v.iter()` | `&T` — ссылки | коллекция остаётся твоей |
| `&mut v` или `v.iter_mut()` | `&mut T` — изменяемые ссылки | коллекция остаётся твоей |
| `v.into_iter()` | `T` — значения | коллекция **перемещается** |

```rust
let numbers = vec![10, 20, 30];

for n in &numbers { }        // n: &i32, numbers живы
for n in numbers { }         // n: i32, numbers перемещён
```

### `next()` вручную

```rust
fn main() {
    let numbers = vec![10, 20, 30];
    let mut it = numbers.iter();

    println!("{:?}", it.next());   // Some(10)
    println!("{:?}", it.next());   // Some(20)
    println!("{:?}", it.next());   // Some(30)
    println!("{:?}", it.next());   // None
}
```

`mut` нужен, потому что `next()` меняет внутреннее состояние итератора — он «помнит», где остановился.

## 3. Ленивость

Это главное свойство, которое отличает итераторы Rust от списковых включений Python.

```rust
let numbers = vec![1, 2, 3];

let doubled = numbers.iter().map(|n| n * 2);   // НИЧЕГО не произошло
```

`map` не вычисляет — он **запоминает**, что надо будет умножить. Работа начинается, когда появляется **потребитель**:

```rust
let doubled: Vec<i32> = numbers.iter().map(|n| n * 2).collect();
println!("{:?}", doubled);      // [2, 4, 6]
```

Почему это важно: ленивый итератор может остановиться раньше.

```rust
let numbers = vec![1, 2, 3, 4, 5];
let first_big = numbers.iter().find(|&&n| n > 2);
println!("{:?}", first_big);      // Some(3)
```

`find` посмотрит три элемента и остановится, а не пройдёт все пять.

Про `|n| n * 2` — это **замыкание**, функция без имени. Подробно в лекции 15; пока читай как «функция, которую применяем к элементу».

## 4. Адаптеры: преобразуют поток

| Метод | Что делает | Пример |
|---|---|---|
| `map(f)` | применить `f` к каждому | `map(\|n\| n * 2)` |
| `filter(p)` | оставить подходящие | `filter(\|n\| n > 0)` |
| `enumerate()` | добавить номер | пары `(0, x)`, `(1, y)` |
| `zip(other)` | соединить два итератора в пары | `(a, b)`, `(c, d)` |
| `take(n)` | взять первые `n` | `take(2)` |
| `skip(n)` | пропустить `n` | `skip(1)` |
| `rev()` | обратный порядок | `rev()` |
| `flat_map(f)` | `map` + развернуть вложенность | `flat_map(\|v\| v.clone())` |

Пример в цепочке:

```rust
let numbers = vec![1, 2, 3, 4, 5, 6];

let result: Vec<i32> = numbers
    .iter()                       // &i32: 1, 2, 3, 4, 5, 6
    .filter(|&&n| n % 2 == 0)     // оставить чётные: 2, 4, 6
    .map(|&n| n * n)              // возвести в квадрат: 4, 16, 36
    .collect();

println!("{:?}", result);         // [4, 16, 36]
```

### Почему `|&&n|` и `|&n|`

Это место путает всех, поэтому разберём по шагам.

- `numbers.iter()` даёт элементы типа `&i32` (ссылка на число);
- `filter` передаёт в функцию **ссылку на элемент итератора**, то есть `&&i32` — ссылка на ссылку;
- `|&&n|` — шаблон: «две ссылки, достань значение в `n`» (шаблоны из лекции 8);
- `map`, в отличие от `filter`, передаёт сам элемент, то есть `&i32`; поэтому там `|&n|`.

Если запутался — можно писать `|n| **n % 2 == 0` и `|n| *n * *n`. Результат тот же, читается хуже.

### `enumerate` и `zip`

```rust
for (i, n) in numbers.iter().enumerate() {
    println!("{i}: {n}");
}

let names = vec!["Аня", "Боря"];
let ages = vec![20, 22];
for (name, age) in names.iter().zip(ages.iter()) {
    println!("{name} — {age}");
}
```

`enumerate` даёт `(номер, элемент)`, `zip` — пары из двух итераторов (останавливается на коротком).

## 5. Потребители: запускают работу

| Метод | Что возвращает |
|---|---|
| `collect::<Vec<_>>()` | коллекция |
| `sum()` | сумма |
| `count()` | количество |
| `fold(init, f)` | аккумулятор |
| `any(p)` / `all(p)` | `bool` |
| `find(p)` | `Option<элемент>` |
| `position(p)` | `Option<usize>` — индекс |
| `max_by_key(f)` / `min_by_key(f)` | `Option<элемент>` |
| `last()` | `Option<элемент>` |
| `for_each(f)` | `()` — выполнить для каждого |

### `fold` — универсальный аккумулятор

```rust
let numbers = vec![1, 2, 3, 4];

let sum = numbers.iter().fold(0, |acc, &n| acc + n);
println!("{sum}");      // 10
```

Читается: «начать с 0, для каждого элемента прибавить его к аккумулятору». `fold(0, |acc, n| acc + n)` — то же, что `sum()`, но общее: можно накапливать строку, максимум, словарь.

### `collect` и запись `::<Vec<_>>`

```rust
let doubled: Vec<i32> = numbers.iter().map(|n| n * 2).collect();
```

Тип результата известен из аннотации `: Vec<i32>`. Если аннотации нет — компилятор не догадается:

```text
error[E0282]: type annotations needed
```

Тогда пишут «рыбку» — `turbo fish`:

```rust
let doubled = numbers.iter().map(|n| n * 2).collect::<Vec<i32>>();
```

`::<Vec<i32>>` — «подставь в `collect` параметр типа `Vec<i32>`». Это та же запись `Тип::имя`, что `String::from`, только с параметром типа.

`collect` умеет собирать не только `Vec`: `HashMap`, `HashSet`, `String` и даже `Result` (лекция 10).

## 6. ML-нить: метрики через итераторы

Самый частый код в ML-препроцессинге — посчитать статистику по `Vec<f64>`.

```rust
fn mean(values: &[f64]) -> Option<f64> {
    if values.is_empty() {
        return None;
    }
    Some(values.iter().sum::<f64>() / values.len() as f64)
}

fn mse(y_true: &[f64], y_pred: &[f64]) -> Option<f64> {
    if y_true.is_empty() || y_true.len() != y_pred.len() {
        return None;
    }
    let sum: f64 = y_true
        .iter()
        .zip(y_pred.iter())
        .map(|(t, p)| (t - p) * (t - p))
        .sum();
    Some(sum / y_true.len() as f64)
}

fn main() {
    let data = vec![2.0, 4.0, 4.0, 4.0, 5.0, 5.0, 7.0, 9.0];
    println!("{:?}", mean(&data));                       // Some(5.0)

    let true_y = vec![3.0, -0.5, 2.0, 7.0];
    let pred_y = vec![2.5, 0.0, 2.0, 8.0];
    println!("{:?}", mse(&true_y, &pred_y));             // Some(0.375)
}
```

Разберём `values.iter().sum::<f64>()`:

- `iter()` — итератор по ссылкам `&f64`;
- `sum::<f64>()` — сложить, приведя к `f64`. Запись `::<f64>` нужна, потому что `sum` обобщённая (лекция 12) и должна знать, что складывать.

И `zip` + `map` в `mse`: пары «истинное / предсказанное», затем квадрат разности, затем сумма. Ровно формула MSE.

Проверим руками: разности `0.5, -0.5, 0.0, -1.0`, квадраты `0.25, 0.25, 0.0, 1.0`, сумма `1.5`, делим на 4 — `0.375`. Сходится.

## 7. Типичные ошибки

### Не выводится тип `collect`

```text
error[E0282]: type annotations needed
```

Добавь `let x: Vec<i32> = ...collect();` или `collect::<Vec<i32>>()`.

### Лишняя или недостаточная ссылка

```text
error[E0308]: mismatched types
expected `&&i32`, found `i32`
```

Это про `filter`: он передаёт `&&i32`. Используй `|&&n|` или `|n| **n > 0`.

### Забыл потребителя

```rust
numbers.iter().map(|n| n * 2);
```

```text
warning: unused `Map` that must be used
note: iterators are lazy and do nothing unless consumed
```

Компилятор прямо говорит: «итераторы ленивы и ничего не делают, пока их не потребить».

### `sum` без типа

```rust
let s = values.iter().sum();
```

```text
error: E0283: type annotations needed
```

`sum` не знает, в каком типе складывать. Нужно `sum::<f64>()` или аннотация.

## 8. Что ты теперь знаешь

- Итератор — объект с `next()`, который возвращает `Option`.
- `iter()` — по ссылкам, `iter_mut()` — изменяемые ссылки, `into_iter()` — по владению.
- Адаптеры (`map`, `filter`, …) ленивы; работу запускает потребитель.
- Потребители: `collect`, `sum`, `count`, `fold`, `find`, `any`, `max_by_key`.
- `filter` даёт `&&T`, `map` — `&T`; отсюда `|&&n|` и `|&n|`.
- `collect::<Vec<_>>()` — «собери в вектор».
- Метрики (`mean`, `mse`) пишутся цепочками итераторов в 3–5 строк.
