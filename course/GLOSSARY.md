# Словарь терминов

Термины в порядке появления в курсе. Каждое определение — в одну-две строки. Если термин встречается в лекции раньше, чем здесь, — это ошибка курса, сообщи.

---

## Лекция 1. Как текст превращается в программу

**Исходный код** — текст программы, который пишет человек.

**Компилятор** — программа, которая переводит исходный код в машинные команды. В Rust компилятор называется `rustc`.

**Скомпилировать** — перевести один кусок исходного кода в машинный код.

**Собрать (build)** — скомпилировать все части проекта (твой код + стандартную библиотеку + чужие библиотеки) и соединить их в один файл.

**Линковка** — соединение скомпилированных частей в один исполняемый файл.

**Запустить** — попросить операционную систему выполнить готовый файл.

**Функция** — именованный кусок кода, который можно выполнить.

**`main`** — функция, с которой начинается выполнение программы. Английское *main* — «главный». Называется «точка входа».

**Строка** (текст) — последовательность символов в двойных кавычках.

**Макрос** — команда компилятору, которая во время сборки разворачивается в код. Отличается восклицательным знаком после имени: `println!`.

**`println!`** — макрос, который печатает текст в консоль и переходит на новую строку.

**Точка с запятой (`;`)** — знак, который завершает команду.

**Комментарий** — текст в коде, который компилятор не читает. Начинается с `//`.

**`cargo`** — стандартный инструмент Rust: создаёт проекты, собирает их и запускает.

## Лекция 2. Значения и типы

**Переменная** — имя, за которым сохранено значение.

**`let`** — слово, создающее переменную: `let x = 5;`.

**Тип** — вид значения: какие операции допустимы и сколько памяти занимает.

**Статическая типизация** — типы всех значений известны до запуска программы и проверяются компилятором.

**Вывод типов** — компилятор сам определяет тип по значению; писать тип не обязательно.

**`mut`** — пометка «эту переменную можно менять». Без неё переменная неизменяема.

**`i32`** — целое число со знаком, 32 бита. Тип по умолчанию для целых.

**`i64`** — целое со знаком, 64 бита.

**`u8`, `u32`, `u64`** — целые **без** знака (только неотрицательные) указанного размера.

**`usize`** — целое без знака размером с указатель; используется для индексов и размеров.

**`f64`** — дробное число двойной точности. Тип по умолчанию для дробных.

**Переполнение** — ситуация, когда результат не влезает в тип (например, 256 для `u8`). В отладочной сборке вызывает панику.

**`bool`** — логический тип, значения `true` и `false`.

**`char`** — ровно один символ Unicode в одинарных кавычках: `'a'`.

**`&str`** — тип неизменяемого текста (строковый литерал); ссылка на текст, вшитый в программу.

**`format!`** — макрос, который собирает строку из частей, не печатая её.

**Подстановка** — запись `{имя}` или `{}` внутри строки, вместо которой подставляется значение.

## Лекция 3. Функции и выражения

**Параметр** — переменная в описании функции, через которую она получает данные.

**Аргумент** — конкретное значение, передаваемое при вызове.

**`->`** — стрелка, после которой пишется тип возвращаемого значения.

**Возвращаемое значение** — то, что функция отдаёт вызывающему.

**Вызов функции** — запись `имя(аргументы)`, которая выполняет функцию.

**Выражение** — код, который вычисляется в значение. Например, `5 + 3` вычисляется в `8`.

**Оператор** — код, который ничего не возвращает, а просто что-то делает. Например, `let x = 5;`.

**`()` (unit)** — тип «пустое значение», означающий «ничего».

**Область видимости (scope)** — часть программы, где имя доступно.

**`return`** — досрочный выход из функции с возвратом значения.

---

## Лекция 4. Условия и циклы

**Условие** — проверка, дающая `true` или `false`.

**`if` / `else` / `else if`** — «если» / «иначе» / «иначе если».

**Логические операторы** — `&&` («и»), `||` («или»), `!` («не»).

**`while`** — цикл, который повторяется, пока условие истинно.

**`loop`** — бесконечный цикл; выходят из него через `break`.

**`for`** — цикл по набору значений или диапазону.

**Диапазон** — запись `0..5` («от 0 до 5, не включая 5») или `0..=5` («включая 5»).

**Итерация** — один проход тела цикла.

**`break`** — немедленно выйти из цикла. В `loop` может вернуть значение: `break x;`.

**`continue`** — пропустить остаток тела и перейти к следующей итерации.

**Массив** — набор значений одного типа фиксированной длины: `[10, 20, 30]`.

**`_`** — «значение не нужно» (в `for _ in 0..3`).

**`%`** — остаток от деления.

## Лекция 5. Владение

**Память** — место, где программа хранит данные.

**Стек** — быстрая память для значений фиксированного размера; освобождается автоматически при выходе из функции.

**Куча** — память «по запросу» для данных переменного размера (текст, растущие списки).

**Владение (ownership)** — правило Rust: у значения в куче ровно один владелец, и он освобождает память.

**Владелец** — переменная, отвечающая за значение.

**Move (перемещение)** — передача владения другому имени. После move старое имя недоступно. Ошибка: `E0382`.

**`Copy`** — свойство простых типов (числа, `bool`, `char`), которые при присваивании **копируются**, а не перемещаются.

**`clone`** — явное полное копирование значения, включая данные в куче.

**`drop`** — автоматическое освобождение памяти, которое компилятор вставляет в конец области видимости владельца.

**`String`** — строка, которая живёт в куче, ею владеет переменная и её можно менять. Создаётся через `String::from("...")`.

**`push_str` / `push`** — дописать текст / дописать один символ в `String`.

**Время жизни значения** — от создания до конца блока, где живёт владелец.

---

## Лекция 6. Заимствование

**Заимствование (borrow)** — дать поработать со значением, не забирая владение.

**Ссылка** — значение, указывающее на другие данные, но не владеющее ими.

**`&`** — неизменяемая ссылка: «взять в долг для чтения».

**`&mut`** — изменяемая ссылка: «взять в долг с правом изменения».

**Borrow checker** — этап компилятора Rust, проверяющий правила заимствования до запуска программы. В готовом коде его нет.

**Время жизни ссылки (lifetime)** — отрезок программы, пока ссылка и данные, на которые она указывает, живы.

**Срез (slice)** — ссылка на часть данных, без владения: `&numbers[1..4]`.

**`deref`-коэрция** — автоматическое превращение `&String` в `&str` при передаче в функцию.

**Граница символа (char boundary)** — позиция в строке, где начинается или кончается целый символ. Срез не по границе вызывает панику.

## Ошибки компилятора, которые уже встречались

| Код | Значит |
|---|---|
| `E0382` | использована переменная, у которой уже забрали владение |
| `E0384` | попытка изменить переменную без `mut` |
| `E0308` | не совпадают типы |
| `E0423` | `println` без `!` |
| `E0425` | имя не найдено в этой области видимости |
| `E0502` | одновременно `&` и `&mut` |
| `E0499` | два `&mut` одновременно |
| `E0515` | возврат ссылки на локальную переменную |
| `E0596` | `&mut` у переменной без `mut` |
| `E0597` | ссылка живёт дольше своих данных |
| `E0601` | нет функции `main` |
| `E0317` | у `if` нет `else`, но его значение используется |
