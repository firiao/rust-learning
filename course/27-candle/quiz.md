# Тест к лекции 27

Ответы — в конце, под `<details>`.

## Вопросы

**1.** Чем `Var` отличается от `Tensor`?

a) ничем
b) `Var` — тензор, по которому можно считать градиенты; `Tensor` — обычные данные
c) `Var` быстрее

**2.** Зачем нужен `VarBuilder` и `.pp("l1")`?

a) чтобы создать параметры с именами `l1.weight`, `l1.bias`
b) чтобы ускорить обучение
c) чтобы включить GPU

**3.** Почему `forward` возвращает логиты, а не вероятности?

a) потому что так быстрее
b) `binary_cross_entropy_with_logit` сам применяет sigmoid; двойной sigmoid ломает обучение
c) Candle не умеет sigmoid

**4.** Что делает `optimizer.backward_step(&loss)`?

a) считает градиенты и обновляет веса
b) только считает loss
c) сохраняет модель

**5.** Почему `VarMap::load` вызывают **после** создания модели?

a) потому что `load` не создаёт переменные, а обновляет существующие по именам
b) для скорости
c) иначе ошибка компиляции

**6.** Что означает `weight_decay: 0.0` в `ParamsAdamW`?

a) отключить L2-регуляризацию (по умолчанию она `0.01`)
b) отключить градиенты
c) снизить learning rate

**7.** Почему `device.set_seed(42)` не помогает на CPU в 0.11.1?

a) это баг, исправленный в новой версии
b) CPU-счётчик не поддерживает seed: `cannot seed the CPU rng with set_seed`
c) `set_seed` только для CUDA

## Ответы

<details>
<summary>Показать</summary>

**1 — b.** `Var` — тензор, помеченный как параметр для autograd.

**2 — a.** Префикс входит в имя переменной, а имя — ключ в safetensors.

**3 — b.** Иначе sigmoid применится дважды: градиент раздавится, loss застрянет около `0.598`.

**4 — a.** Один вызов: backward + шаг оптимизатора.

**5 — a.** Загружать некуда, пока переменных нет.

**6 — a.** `ParamsAdamW::default().weight_decay == 0.01`.

**7 — b.** На CPU генератор не поддерживает установку seed.
