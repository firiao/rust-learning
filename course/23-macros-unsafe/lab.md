# Лаба 23. Макросы и `unsafe`

**Время:** ~20 минут
**Тема:** `macro_rules!` — шаблоны, захват, повторение; `unsafe` — что и зачем

> **Языковой бюджет:** только то, что объяснено в лекциях 1–23. Полная таблица — [BUDGET.md](../BUDGET.md).

## Цель

Написать три макроса. Плюс понять, почему `unsafe` — не «выключить Rust».

## Крейт уже создан

Открывай `practice/l23-macros`. Каждый макрос пока разворачивается в `not_implemented()`,
поэтому тесты компилируются, но падают:

```bash
cargo test -p l23-macros     # 3 красных: panicked at 'макрос ещё не реализован'
```

Заготовка сделана так специально: `todo!()` прямо в теле макроса ломает вывод типов
(`assert_eq!(todo!(), 6)` — «cannot infer type»). Поэтому стоит `not_implemented::<T>()`,
и тип указан явно.

## Реализуй три макроса

**1. `sum_all!(1, 2, 3)` → `6`** — сумма любого числа выражений (включая ноль).

Подсказка: `0 $(+ $x)*`.

**2. `max_of!(3, 7, 2)` → `7`** — максимум из двух и более выражений.

Подсказка: завести `let mut best = $first;` и пройти по `$rest` через `$( ... )+`.

**3. `strings!("а", "б")` → `vec!["а".to_string(), "б".to_string()]`**

Подсказка: `vec![$(String::from($x)),*]`.

Тесты уже написаны — просто доведи до зелёного.

## Эксперимент с `unsafe`

Добавь в конец файла (и потом убери):

```rust
// #[test]
// fn raw_pointer() {
//     let x = 5;
//     let p = &x as *const i32;
//     let value = unsafe { *p };
//     assert_eq!(value, 5);
// }
```

Раскомментируй, запусти, потом попробуй **убрать** `unsafe` — компилятор потребует его обратно.
Запиши в `NOTES.md`, какая операция потребовала `unsafe` и почему.

## Подсказки

<details>
<summary>`sum_all`</summary>

```rust
macro_rules! sum_all {
    ($($x:expr),*) => {
        0 $(+ $x)*
    };
}
```

`$(+ $x)*` — «повторить `+ $x` для каждого аргумента». Раскрытие: `0 + 1 + 2 + 3`.
Для нуля аргументов останется `0`.

</details>

<details>
<summary>`max_of`</summary>

```rust
macro_rules! max_of {
    ($first:expr, $($rest:expr),+) => {
        {
            let mut best = $first;
            $(
                if $rest > best {
                    best = $rest;
                }
            )+
            best
        }
    };
}
```

Фигурные скобки вокруг тела нужны, чтобы макрос был одним **выражением** и `let` внутри
не «протёк» в вызывающий код.

</details>

<details>
<summary>`strings`</summary>

```rust
macro_rules! strings {
    ($($x:expr),*) => {
        vec![$(String::from($x)),*]
    };
}
```

</details>

<details>
<summary>Про `unsafe`</summary>

```rust
let value = unsafe { *p };
```

`unsafe` здесь нужен потому, что разыменование сырого указателя (`*const i32`) компилятор проверить
не может: он не знает, жив ли объект и не «протух» ли адрес.

Важно: `unsafe` **не отключает** borrow checker. Правила владения действуют и внутри блока.

</details>
