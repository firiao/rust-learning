# Лаба 1. Первая программа

**Время:** ~15 минут
**Тема:** `cargo`, `fn main`, `println!`, чтение ошибок компилятора

## Цель

Создать проект, написать программу, специально сломать её и починить — прочитав сообщение компилятора.

## Крейт уже создан

Открывай `practice/l01-hello` — там уже написана программа:

```rust
fn main() {
    println!("Первая программа");
    println!("Она умеет печатать текст");

    greeting();
}

fn greeting() {
    println!("---");
    println!("это отдельная функция");
}
```

Запусти её:

```bash
cargo run -p l01-hello
```

Разбери по частям: `main` — точка входа, `greeting` — обычная функция, которую `main` вызывает. Обрати внимание, что `greeting` описана **после** `main`, и это нормально.

## Поменяй текст

Замени оба текста на свои и добавь ещё один вызов `greeting()`. Убедись, что `greeting` выполняется столько раз, сколько вызовов.

## Сломай и почини

Три эксперимента. В каждом: меняешь код → `cargo run` → читаешь ошибку → **записываешь её номер** → возвращаешь как было.

**Эксперимент 1.** Убери `!` у `println`:

```rust
println("текст");
```

Запиши: код ошибки и строку `help:`.

**Эксперимент 2.** Убери `;` после первой команды, но оставь после неё вторую:

```rust
fn main() {
    println!("первая")
    println!("вторая");
}
```

Запиши: что компилятор считает «лишним» и куда показывает стрелкой.

**Эксперимент 3.** Поставь `'текст'` в одинарные кавычки.

Запиши: что такое `character literal` и почему ошибка.

## Критерии приёмки

- [ ] `cargo run -p l01-hello` печатает твой текст;
- [ ] функция `greeting()` вызывается из `main` и выполняется нужное число раз;
- [ ] все три эксперимента воспроизведены, ошибки прочитаны;
- [ ] в `NOTES.md` записаны коды ошибок (`E0xxx` или текст) для всех трёх экспериментов;
- [ ] `cargo fmt -p l01-hello` и `cargo clippy -p l01-hello -- -D warnings` не ругаются.

## Подсказки

<details>
<summary>Как читать ошибку компилятора</summary>

Порядок такой:

1. **Первая строка** — что не так (`error[E0423]: cannot find function ...`).
2. **Стрелки** — где именно (`^^^` указывает на проблемное место).
3. **Строки `help:` и `note:`** — что делать. Там чаще всего готовое решение.
4. **Номер `E0xxx`** — для подробностей: `rustc --explain E0423`.

Не читай ошибку «по диагонали»: 80% времени экономится именно на последних строках.

</details>

<details>
<summary>Что должно получиться в экспериментах</summary>

**1.** `error[E0423]: cannot find function 'println' in this scope`, затем `note: a macro named 'println' exists in another namespace` и `help: use '!' to invoke the macro`.

**2.** `error: expected ';', found 'println'` и `help: add ';' here` — стрелка на **конец первой строки**, потому что именно там не закончилась команда.

**3.** `error: character literal may only contain one codepoint` и `help: if you meant to write a string literal, use double quotes`.

</details>

<details>
<summary>Если cargo не находит пакет</summary>

Ты не в корне курса. Проверь:

```bash
cd ~/rust-learning
cargo metadata --no-deps --format-version 1 | grep l01-hello
```

Если пусто — крейт не попал в workspace: `members` в корневом `Cargo.toml` содержит `"practice/*"`, значит папка должна лежать именно в `practice/`.

</details>
