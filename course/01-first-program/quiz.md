# Тест к лекции 1

Ответы — в конце, под `<details>`. Не подглядывай.

## Вопросы

**1.** Чем «скомпилировать» отличается от «собрать»?

a) ничем, это синонимы
b) скомпилировать — перевести один кусок кода; собрать — скомпилировать всё и соединить в один файл
c) собрать — это запустить программу

**2.** Почему готовая программа на Rust запускается на машине, где Rust не установлен?

a) Rust встраивается в операционную систему
b) компилятор заранее перевёл код в машинные команды, и программа не нуждается в переводчике
c) программа скачивает компилятор при первом запуске

**3.** Что означает `fn` в начале строки?

a) «функция»
b) «файл»
c) «финал»

**4.** Почему выполнение программы начинается именно с `main`?

a) это слово зарезервировано языком как точка входа
b) потому что `main` — первая функция в файле
c) потому что `main` — самая короткая функция

**5.** Зачем у `println!` восклицательный знак?

a) это украшение, можно не писать
b) это макрос — он собирает код под конкретное число аргументов, чего функция не может
c) это означает «печатать с новой строки»

**6.** Что произойдёт, если написать `println("Привет");`?

a) напечатает «Привет»
b) ошибка `cannot find function println` с подсказкой добавить `!`
c) напечатает пустую строку

**7.** Что делает `cargo run`?

a) только запускает уже собранный файл
b) собирает (если нужно) и запускает
c) только собирает

**8.** Где лежит код, который ты пишешь в проекте, созданном `cargo new hello`?

a) `hello/main.rs`
b) `hello/src/main.rs`
c) `hello/Cargo.toml`

**9.** Зачем нужна точка с запятой в конце `println!("Привет");`?

a) она завершает команду
b) она нужна только для красоты
c) без неё программа не запустится

---

## Ответы

<details>
<summary>Показать</summary>

**1 — b.** Компилирует `rustc` — один кусок кода. Собирает `cargo` — весь проект: компилирует все части и **линкует** их в один файл (слово «линковка» — соединение).

**2 — b.** Компилятор заранее сделал машинные команды. В отличие от Python (нужен интерпретатор) и Java (нужна JVM), Rust-программа самодостаточна.

**3 — a.** `fn` — сокращение от *function*. Дальше идёт имя: `fn main` — «функция с именем main».

**4 — a.** `main` — договорённость с операционной системой: она ищет функцию с таким именем и начинает с неё. Если её нет, компилятор скажет `E0601: main function not found`.

**5 — b.** Функция принимает фиксированное число аргументов известных типов. `println!` должен принимать **любое** число аргументов **любых** типов — поэтому это макрос, который разворачивается во время компиляции.

**6 — b.** Точный текст: `error[E0423]: cannot find function 'println' in this scope` + `note: a macro named 'println' exists` + `help: use '!' to invoke the macro`. Всегда читай строки `help:`.

**7 — b.** `cargo run` = «собери, если изменилось, и запусти». Отдельно собирать не нужно.

**8 — b.** `src/main.rs`. Папка `src` — от *source*, «исходники».

**9 — a.** Завершает команду. Без неё компилятор попытается склеить строки и выдаст `expected ';', found ...`. (Есть нюанс с последней строкой функции — он будет в лекции 3.)

</details>
