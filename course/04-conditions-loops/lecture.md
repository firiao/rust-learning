# Лекция 4. Условия и циклы

**Время:** ~25 минут

**Нужно знать заранее:** `let`, `mut`, `bool`, сравнения (`==`, `>`), функции, `->`, выражения и `;` из лекций 2–3.

**Новые слова в этой лекции:**
- **условие** — проверка, которая даёт `true` или `false`;
- **`if` / `else` / `else if`** — «если» / «иначе» / «иначе если»;
- **логические операторы** — `&&` («и»), `||` («или»), `!` («не»);
- **`while`** — цикл «пока условие истинно»;
- **`loop`** — бесконечный цикл, из которого выходят через `break`;
- **`for`** — цикл по набору значений;
- **диапазон** — запись вида `0..5` («от 0 до 5»);
- **итерация** — один проход тела цикла;
- **`break`** — немедленно выйти из цикла;
- **`continue`** — перейти к следующей итерации, пропустив остаток тела;
- **массив** — набор значений одного типа фиксированной длины.

## 1. `if`: выполнить код при условии

До этого программы выполняли всё подряд. Теперь нужна возможность **выбрать**.

```rust
fn main() {
    let temperature = 25;

    if temperature > 20 {
        println!("тепло");
    }
}
```

```text
тепло
```

Разберём:

- `if` — «если»;
- `temperature > 20` — **условие**. Оно вычисляется в `true` или `false` (тип `bool` из лекции 2);
- `{ println!("тепло"); }` — что сделать, если условие истинно.

Если условие ложно, блок просто пропускается и программа идёт дальше.

### `else` и `else if`

```rust
fn main() {
    let temperature = 25;

    if temperature > 25 {
        println!("жарко");
    } else if temperature > 15 {
        println!("тепло");
    } else {
        println!("прохладно");
    }
}
```

```text
тепло
```

- `else if` — «иначе, если». Проверяется, только если предыдущее условие ложно;
- `else` — «во всех остальных случаях». Идёт последним и условия не имеет.

Проверка идёт **сверху вниз**, срабатывает первая подходящая ветка. Дальше проверки не выполняются. Поэтому порядок важен: если бы `temperature > 15` стояло первым, то при 30 сработала бы именно эта ветка, и «жарко» никогда бы не напечаталось.

### Условие обязано быть `bool`

```rust
let x = 5;
if x { }        // ошибка
```

```text
error[E0308]: mismatched types
  |
2 |     if x {
  |        ^ expected `bool`, found integer
```

В Python `if x:` сработает для любого ненулевого числа. В Rust так нельзя: условие — только `true` или `false`. Это убирает целый класс недоразумений.

## 2. `if` — это выражение, оно даёт значение

В лекции 3 мы выяснили: выражение вычисляется в значение. `if` тоже выражение.

Значит, результат `if` можно присвоить переменной:

```rust
fn main() {
    let temperature = 25;

    let status = if temperature > 20 { "тепло" } else { "прохладно" };
    println!("{status}");
}
```

```text
тепло
```

Как это читается: «переменная `status` равна `"тепло"`, если температура больше 20, иначе `"прохладно"`».

В Python так нельзя (там нужен `x if cond else y`), в Java — только для простых значений (тернарный `?:`). В Rust `if` — полноценное выражение, как `5 + 3`.

Два правила:

1. **Ветки должны давать значения одного типа.** Одна ветка возвращает `&str`, другая `i32` — ошибка.
2. Если у `if` нет `else`, значение не определено, и использовать его нельзя — только как обычный блок.

```rust
let x = if true { 1 } else { 2 };      // ok: обе ветки i32
let y = if true { 1 };                 // ошибка: нет else, значение неполное
```

```text
error[E0317]: `if` may be missing an `else` clause
```

«Возможно, у `if` не хватает `else`» — потому что без `else` непонятно, чему равно значение, когда условие ложно.

## 3. `while`: пока условие истинно

**Цикл** — это повторение кода. Первый вид: повторять, **пока** условие выполняется.

```rust
fn main() {
    let mut counter = 3;

    while counter > 0 {
        println!("{counter}");
        counter = counter - 1;
    }

    println!("поехали");
}
```

```text
3
2
1
поехали
```

По шагам:

1. Проверяется `counter > 0` → `3 > 0` истинно → тело выполняется;
2. Печатается `3`, `counter` уменьшается до 2;
3. Проверяется `2 > 0` → истинно → печать `2`, `counter` = 1;
4. Проверяется `1 > 0` → истинно → печать `1`, `counter` = 0;
5. Проверяется `0 > 0` → **ложно** → цикл заканчивается, идём к `println!("поехали")`.

Каждый проход тела называется **итерацией**. Здесь три итерации.

**Главная опасность:** если внутри цикла не менять то, что влияет на условие, он будет выполняться вечно. Забыть `counter = counter - 1` — классическая ошибка. Программа зависнет, и её придётся прерывать (`Ctrl+C`).

`mut` здесь обязателен: мы меняем `counter` внутри цикла.

## 4. `loop`: бесконечный цикл с выходом через `break`

Иногда неизвестно заранее, сколько будет итераций. Тогда пишут `loop` — цикл без условия:

```rust
fn main() {
    let mut counter = 0;

    loop {
        counter = counter + 1;
        if counter == 5 {
            break;
        }
    }

    println!("{counter}");   // 5
}
```

**`break`** — «выйти из цикла немедленно». После него цикл заканчивается, выполнение продолжается со строки после закрывающей `}`.

Без `break` такой цикл бесконечен. Это нормально и иногда нужно: `loop` с выходом по событию — стандартная конструкция.

### `break` может вернуть значение

`loop` — единственный цикл в Rust, который умеет отдавать результат:

```rust
fn main() {
    let mut counter = 0;

    let found = loop {
        counter = counter + 1;
        if counter * counter > 50 {
            break counter;      // выходим и возвращаем значение
        }
    };

    println!("{found}");        // 8: 8*8 = 64 > 50, а 7*7 = 49 — нет
}
```

`break counter;` означает «выйти и сделать значением цикла `counter`». Это избавляет от «переменной-флага»: не нужно заводить `let mut result = 0;` и присваивать её в середине.

## 5. `for`: цикл по набору значений

Самый частый цикл. Он перебирает значения из набора, не требуя ручного счётчика.

### Диапазон

```rust
fn main() {
    for i in 0..5 {
        println!("{i}");
    }
}
```

```text
0
1
2
3
4
```

Разберём `for i in 0..5`:

- `for` — «для каждого»;
- `i` — имя переменной, в которую попадёт очередное значение;
- `in` — «из»;
- `0..5` — **диапазон** «от 0 до 5».

`0..5` — это `0, 1, 2, 3, 4`. **Правая граница не включается.** Это как `range(0, 5)` в Python.

Если нужно включить правую границу — пишут `..=`:

```rust
for i in 1..=5 {
    println!("{i}");     // 1, 2, 3, 4, 5
}
```

`..=` читается «до ... включительно».

Запомни разницу, она нужна постоянно:

| Запись | Значения | Сколько |
|---|---|---|
| `0..5` | 0, 1, 2, 3, 4 | 5 |
| `0..=5` | 0, 1, 2, 3, 4, 5 | 6 |
| `1..=3` | 1, 2, 3 | 3 |

### Можно не использовать переменную

Если само число не нужно, а нужно просто повторить действие, пишут `_` (подчёркивание) — это значит «значение не нужно»:

```rust
for _ in 0..3 {
    println!("привет");
}
```

Три раза «привет», без предупреждения о неиспользуемой переменной.

### Цикл по массиву

**Массив** — набор значений одного типа, длина известна заранее:

```rust
fn main() {
    let numbers = [10, 20, 30];

    for n in numbers {
        println!("{n}");
    }
}
```

```text
10
20
30
```

Массив записывается в квадратных скобках, значения через запятую. `for n in numbers` берёт значения по одному.

Пока достаточно уметь перебрать массив. Подробности (сколько он занимает, что с ним можно делать) — позже.

## 6. `break` и `continue`

Оба управляют циклом. `break` — выйти совсем, `continue` — пропустить остаток и перейти к следующей итерации.

```rust
fn main() {
    for n in 1..=10 {
        if n % 2 == 0 {
            continue;        // чётные пропускаем
        }
        if n > 7 {
            break;           // дальше не идём
        }
        println!("{n}");
    }
}
```

```text
1
3
5
7
```

Что происходит:

- `n % 2 == 0` — `%` это остаток от деления. `n % 2` равно 0 у чётных. Значит `continue` пропускает чётные;
- `n > 7` — при `n = 8` мы бы вышли, но 8 нечётным не бывает; при `n = 9` сработает `break`. До `println!` дело не дойдёт, и 9 не напечатается.

`%` — оператор остатка от деления. `7 % 3` равно 1. В Python то же самое.

## 7. Типичные ошибки

### Ветки `if` дают разные типы

```rust
let x = if true { 1 } else { "два" };
```

```text
error[E0308]: `if` and `else` have incompatible types
```

Обе ветки должны давать значение **одного типа**: либо два числа, либо две строки.

### Забыл `mut` в `while`

```rust
let counter = 3;
while counter > 0 {
    counter = counter - 1;    // ошибка: нельзя менять
}
```

```text
error[E0384]: cannot assign twice to immutable variable
```

Решение — `let mut counter = 3;` (лекция 2).

### Вечный цикл

Если `while` никогда не станет ложным — программа зависнет. Признак: терминал перестал реагировать. Выход — `Ctrl+C`.

### Путаница `..` и `..=`

```rust
for i in 0..5 { }    // 5 итераций: 0,1,2,3,4
for i in 0..=5 { }   // 6 итераций: 0,1,2,3,4,5
```

## 8. Что ты теперь знаешь

- `if` / `else if` / `else` выбирают ветку; порядок проверки — сверху вниз.
- Условие обязано быть `bool`, а не «любым числом».
- `if` — выражение, его результат можно присвоить; обе ветки одного типа.
- `while` крутится, пока условие истинно; внутри нужно менять то, что влияет на условие.
- `loop` — бесконечный; выходят через `break`; `break значение` возвращает результат.
- `for` перебирает диапазон (`0..5`, `1..=5`) или массив.
- `0..5` не включает 5, `0..=5` включает.
- `break` выходит из цикла, `continue` пропускает итерацию.
- `_` — «значение не нужно».
