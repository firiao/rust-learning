# Тест к лекции 4

Ответы — в конце, под `<details>`.

## Вопросы

**1.** Почему это не компилируется?

```rust
let x = 5;
if x { }
```

a) `if` требует скобок
b) условие должно быть `bool`, а `x` — число
c) `if` нельзя использовать с переменными

**2.** Сколько раз выполнится тело?

```rust
for i in 0..3 { println!("{i}"); }
```

a) 3
b) 4
c) 2

**3.** Сколько значений в `1..=5`?

a) 4
b) 5
c) 6

**4.** Как вернуть значение из `loop`?

a) через `return`
b) через `break значение`
c) никак

**5.** Что делает `continue`?

a) выходит из цикла
b) пропускает остаток тела и переходит к следующей итерации
c) начинает цикл заново с нуля

**6.** Что выведет?

```rust
let n = 10;
let kind = if n % 2 == 0 { "чёт" } else { "нечет" };
println!("{kind}");
```

a) `чёт`
b) `нечет`
c) ошибка: `if` нельзя присвоить

**7.** Почему в `while` нужен `mut` у счётчика?

a) `while` требует изменяемых переменных
b) потому что внутри цикла счётчик меняется
c) не нужен

**8.** Что будет, если в `while` забыть изменить счётчик?

a) ошибка компиляции
b) цикл будет выполняться бесконечно
c) цикл выполнится один раз

**9.** Что вернёт этот код?

```rust
let mut counter = 0;
let result = loop {
    counter += 1;
    if counter == 3 {
        break counter * 10;
    }
};
```

a) `3`
b) `30`
c) `()`

---

## Ответы

<details>
<summary>Показать</summary>

**1 — b.** Условие — только `bool`. В Python `if x:` сработало бы для ненулевого, в Rust — `E0308: expected bool, found integer`.

**2 — a.** `0..3` — полуинтервал: `0, 1, 2`.

**3 — b.** `1..=5` включает правую границу: `1, 2, 3, 4, 5`.

**4 — b.** `break значение` — единственный способ отдать результат из `loop`.

**5 — b.** `continue` пропускает остаток тела и переходит к следующей итерации. Из цикла выходит `break`.

**6 — a.** `10 % 2 == 0`, значит первая ветка. `if` — выражение, его результат присваивается.

**7 — b.** Счётчик меняется в теле — без `mut` это `E0384`.

**8 — b.** Условие никогда не станет ложным — программа зависнет. Выход — `Ctrl+C`.

**9 — b.** `counter` станет 3, `break 3 * 10` вернёт 30. `loop` с `break значение` — выражение.

</details>
