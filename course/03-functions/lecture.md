# Лекция 3. Функции и выражения

**Время:** ~25 минут

**Нужно знать заранее:** [лекции 1](../01-first-program/lecture.md) и [2](../02-values/lecture.md) — `fn main`, `let`, `mut`, типы, `println!`.

**Новые слова в этой лекции:**
- **функция** — именованный кусок кода, который можно выполнить сколько угодно раз;
- **параметр** — переменная, через которую функция получает входные данные (в описании функции);
- **аргумент** — конкретное значение, которое передают при вызове;
- **`->`** — стрелка, после которой пишут тип возвращаемого значения;
- **возвращаемое значение** — то, что функция отдаёт вызывающему;
- **вызов функции** — момент, когда функцию выполняют;
- **выражение** — код, который **вычисляется в значение** (например, `5 + 3` вычисляется в `8`);
- **оператор** — код, который **ничего не возвращает**, а просто что-то делает (например, `let x = 5;`);
- **`()`** (unit) — «пустое значение», означающее «ничего»;
- **область видимости** — часть программы, где имя доступно.

## 1. Зачем нужны функции

Пока все программы состояли из одной `main` в несколько строк. Это работает для «напечатай привет». Для чего-то большего нужно **переиспользовать** куски кода.

**Функция** — это именованный кусок кода. Один раз описал — вызываешь сколько нужно.

```rust
fn main() {
    println!("Привет");
    println!("Привет");
    println!("Привет");
}
```

Так можно, но если понадобится менять приветствие в десяти местах — придётся править десять строк. С функцией — одно:

```rust
fn greet() {
    println!("Привет");
}

fn main() {
    greet();
    greet();
    greet();
}
```

```text
Привет
Привет
Привет
```

Разберём:

- `fn greet()` — **описание** функции с именем `greet`. Скобки пустые — функция ничего не получает. Тело в `{ }` — что она делает.
- `greet();` — **вызов**. Круглые скобки после имени означают «выполни это». Внутри `main` вызвали три раза — код выполнился три раза.

Важно: описание функции само по себе ничего не делает. Пока её не вызовут, она просто лежит в файле.

Порядок в файле не важен: `greet` можно объявить и до `main`, и после — компилятор разберётся.

## 2. Параметры: функция получает данные

Функция без параметров всегда делает одно и то же. Чтобы она зависела от входных данных, нужны **параметры**.

```rust
fn greet(name: &str) {
    println!("Привет, {name}!");
}

fn main() {
    greet("Аня");
    greet("Боря");
}
```

```text
Привет, Аня!
Привет, Боря!
```

Разберём `fn greet(name: &str)`:

- `name` — **параметр**, имя внутри функции, как переменная;
- `:` — «имеет тип»;
- `&str` — тип параметра (строка, помнишь из лекции 2).

**Параметр** — это то, что написано в описании функции. **Аргумент** — конкретное значение при вызове. В `greet("Аня")` аргумент — `"Аня"`.

Два параметра разделяются запятой:

```rust
fn describe(name: &str, age: i32) {
    println!("{name}, {age} лет");
}

fn main() {
    describe("Аня", 20);
}
```

При вызове аргументы должны идти **в том же порядке** и иметь **те же типы**. Перепутал — ошибка компиляции, а не «странный результат». Это хорошо: ошибка видна сразу.

## 3. Возвращаемое значение

Функция может не только печатать, но и **возвращать** результат, который потом используется.

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    let sum = add(2, 3);
    println!("{sum}");   // 5
}
```

Разберём `fn add(a: i32, b: i32) -> i32`:

- `a: i32`, `b: i32` — два параметра типа `i32`;
- **`->`** — стрелка, после неё пишут тип того, что функция возвращает;
- `i32` после стрелки — «функция возвращает целое число».

Тело функции — `a + b` без точки с запятой. Именно поэтому оно становится возвращаемым значением.

### Самое важное правило Rust

**Последнее выражение в функции без `;` — это её возвращаемое значение.**

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b        // без ; — это значение функции
}
```

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b;       // с ; — значение выброшено, функция вернёт ()
}
```

Второй вариант не скомпилируется, но по неожиданной причине: функция обещала вернуть `i32`, а вернула «ничего». Компилятор скажет:

```text
error[E0308]: mismatched types
 --> main.rs:1:27
  |
1 | fn add(a: i32, b: i32) -> i32 {
  |    ---                    ^^^ expected `i32`, found `()`
  |    |
  |    implicitly returns `()` as its body has no tail or `return` expression
2 |     a + b;
  |          - help: remove this semicolon to return this value
```

Читай последнюю строку: `help: remove this semicolon to return this value` — «убери точку с запятой, чтобы вернуть это значение». Компилятор указывает стрелкой прямо на виновника.

Вот и ответ на вопрос из лекции 1: почему в последней строке `main` точка с запятой не нужна. Потому что `main` ничего не возвращает (вернее, возвращает «ничего»), и `;` там роли не играет. А в функции, которая что-то возвращает, точка с запятой **убивает** возврат.

Это одна из самых частых ошибок у новичков. Запомни: **`;` в конце последней строки = «выбросить результат»**.

## 4. Выражения и операторы

Это различие объясняет половину синтаксиса Rust, поэтому разберём аккуратно.

**Выражение** — это код, который **вычисляется в какое-то значение**.

```rust
5 + 3          // вычисляется в 8
add(2, 3)      // вычисляется в 5
"привет"       // вычисляется в строку
```

**Оператор** — это код, который **не даёт значения**, а просто что-то делает. Чаще всего — создаёт переменную.

```rust
let x = 5;     // оператор: создаёт переменную, значения «наружу» не отдаёт
```

Почему это важно: `let` — оператор, поэтому **нельзя** написать `let x = let y = 5;`. Правая часть после `=` обязана быть выражением.

А ещё из этого следует, что **фигурные скобки `{ }` тоже выражение**. Блок кода вычисляется в значение своего последнего выражения:

```rust
fn main() {
    let x = {
        let a = 2;
        let b = 3;
        a + b          // значение блока — 5
    };
    println!("{x}");   // 5
}
```

Такой блок — мини-функция без имени. Встречается реже, но объясняет общее правило: **последнее выражение без `;` — это значение**.

## 5. `()` — «ничего»

В сообщении об ошибке выше было `found ()`. Что это?

**`()`** (читается «юнит», от англ. *unit*) — это тип «пустое значение», то есть «ничего не возвращается».

```rust
fn greet() {          // по сути fn greet() -> ()
    println!("Привет");
}
```

`greet` ничего не возвращает — значит возвращает `()`. Это аналог `void` в Java и `None` в Python, только `()` — настоящий тип, а не особый случай.

Полезно понимать: `println!` тоже возвращает `()` — она печатает и ничего не отдаёт. Поэтому нельзя написать `let x = println!("a");` и получить что-то осмысленное: `x` будет `()`.

## 6. `return` — досрочный выход

Обычно значение — последнее выражение. Но иногда нужно выйти **раньше**:

```rust
fn absolute(x: i32) -> i32 {
    if x < 0 {          // «если x меньше нуля, то...»
        return -x;      // выходим немедленно
    }
    x                   // иначе — последнее выражение
}
```

Здесь впервые появляется `if`. Читается буквально: **`if` условие `{ что делать }`** — «если условие истинно, выполни блок». Всё, что нужно знать для этого примера: `x < 0` сравнивает `x` с нулём, а блок выполняется только при истинном сравнении. Подробно `if` (включая `else` и то, что `if` умеет возвращать значение) — в лекции 4.

`return значение;` прекращает выполнение функции прямо здесь и возвращает значение.

Обрати внимание: после `return` стоит `;`, и это правильно — `return` это оператор, он ничего не «вычисляет», а управляет выполнением.

В Rust `return` используют **редко** — только для раннего выхода из середины функции. Длинная функция, где каждая ветка кончается `return x;`, — это стиль из Java и C; в Rust так не пишут.

`if` без `else` в примере выше не даёт значения, поэтому это законно: если условие истинно — вышли через `return`, если нет — идём дальше к `x`. `if` как выражение мы разберём в лекции 4.

## 7. Функции вызывают функции

Ничего не мешает одной функции вызывать другую:

```rust
fn square(x: i32) -> i32 {
    x * x
}

fn sum_of_squares(a: i32, b: i32) -> i32 {
    square(a) + square(b)
}

fn main() {
    println!("{}", sum_of_squares(3, 4));   // 25
}
```

Читается сверху вниз: `main` вызывает `sum_of_squares`, та дважды вызывает `square`.

Так и строятся программы: маленькие функции, из них — побольше, из тех — ещё больше.

## 8. Область видимости

```rust
fn main() {
    let x = 5;
    {
        let y = 10;
        println!("{x} {y}");   // обе видны
    }
    // println!("{y}");        // ошибка: y здесь уже нет
}
```

**Область видимости** — часть программы, где имя доступно. Переменная живёт от `let` до конца блока `{ }`, в котором она создана.

`x` объявлена в теле `main`, поэтому видна до конца `main`, включая вложенный блок. `y` объявлена во вложенном блоке и умирает на его закрывающей `}`.

Ошибка при обращении к `y` снаружи:

```text
error[E0425]: cannot find value `y` in this scope
```

`scope` — «область видимости». Это знакомо и по Python (переменная внутри функции не видна снаружи), и по Java.

## 9. Что ты теперь знаешь

- `fn имя(параметры) -> тип { тело }` описывает функцию.
- Вызов — `имя(аргументы)`.
- **Последнее выражение без `;` — возвращаемое значение.** С `;` результат выбрасывается.
- `-> i32` означает «возвращает целое число».
- `()` — «ничего»; функция без `->` возвращает `()`.
- Выражение вычисляется в значение, оператор — нет. `let` — оператор.
- `return` — для раннего выхода.
- Переменная живёт до конца блока, где объявлена.
