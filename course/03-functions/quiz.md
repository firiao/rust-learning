# Тест к лекции 3

Ответы — в конце, под `<details>`.

## Вопросы

**1.** Что не так с этой функцией?

```rust
fn double(x: i32) -> i32 {
    x * 2;
}
```

a) всё в порядке
b) лишняя `;` — функция возвращает `()`, а не `i32`
c) нужен `return`

**2.** Что означает `-> f64` в описании функции?

a) функция принимает `f64`
b) функция возвращает `f64`
c) функция сравнивает с `f64`

**3.** Чем параметр отличается от аргумента?

a) ничем
b) параметр — имя в описании функции, аргумент — конкретное значение при вызове
c) параметр — это тип, аргумент — значение

**4.** Что вернёт эта функция при `f(-3)`?

```rust
fn f(x: i32) -> i32 {
    if x > 0 {
        return x;
    }
    -x
}
```

a) `-3`
b) `3`
c) `0`

**5.** Что такое `()`?

a) пустая функция
b) тип «ничего»; его возвращает функция без `->`
c) ошибка компиляции

**6.** Что вычисляется в этом блоке?

```rust
let x = {
    let a = 2;
    let b = 3;
    a + b
};
```

a) `x = 2`
b) `x = 5`
c) ошибка: блок нельзя присвоить

**7.** `let` — это выражение или оператор?

a) выражение: возвращает значение
b) оператор: ничего не возвращает
c) зависит от контекста

**8.** Почему нельзя обратиться к переменной, объявленной во вложенном блоке, снаружи?

a) она удалена сборщиком мусора
b) она живёт только до конца блока, где объявлена (область видимости)
c) это разрешено, ошибки нет

---

## Ответы

<details>
<summary>Показать</summary>

**1 — b.** `x * 2;` — выражение с `;`, результат выброшен. Функция обещала `i32`, а вернула `()`. Компилятор подскажет `help: remove this semicolon to return this value`.

**2 — b.** Стрелка `->` вводит тип возвращаемого значения.

**3 — b.** В `fn greet(name: &str)` параметр — `name`. В вызове `greet("Аня")` аргумент — `"Аня"`.

**4 — b.** `x > 0` ложно, `return` не срабатывает, исполняется последнее выражение `-x` = `3`.

**5 — b.** `()` — unit, «пустое значение». Функция без `->` возвращает `()`.

**6 — b.** Блок — выражение; его значение — последнее выражение без `;`, то есть `a + b = 5`.

**7 — b.** `let` — оператор, поэтому `let x = let y = 5;` не компилируется: справа от `=` должно быть выражение.

**8 — b.** Область видимости: переменная живёт от `let` до закрывающей `}` своего блока. Снаружи — `E0425: cannot find value in this scope`.

</details>
