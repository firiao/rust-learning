# Лаба 3. Функции и возврат

**Время:** ~15 минут
**Тема:** параметры, `->`, последнее выражение, `return`, `()`

> **Языковой бюджет:** только лекции 1–3. Здесь **нет** `if` и циклов — они в лекции 4.

## Цель

Пять функций, где главное — правильно вернуть значение: выражением, а не `return`-ом на каждой ветке.

## Реализуй

| Функция | Что делает |
|---|---|
| `add(a, b)` | сумма двух `i32` |
| `square(x)` | квадрат |
| `volume(w, h, d)` | объём параллелепипеда |
| `average3(a, b, c)` | среднее трёх `f64` |
| `print_and_count(text)` | печатает и **возвращает** число символов |

Всё — одно выражение в теле. Никаких `return` не нужно (кроме случая, когда захочешь
попробовать его в эксперименте).

## Эксперимент

Перепиши `add` через `return`:

```rust
pub fn add(a: i32, b: i32) -> i32 {
    return a + b;
}
```

Компилируется. А теперь попробуй убрать точку с запятой после `a + b` в обычной версии
и наоборот добавить `;` в конце тела — объясни в `NOTES.md`, что ломается и почему.

## Критерии приёмки

- [ ] 5 тестов зелёные;
- [ ] у функций с `->` нет точки с запятой после последнего выражения;
- [ ] `print_and_count` и печатает, и возвращает;
- [ ] `clippy -D warnings` и `fmt --check` чистые после реализации;
- [ ] в `NOTES.md` записано, что происходит с `;` в конце тела.

## Подсказки

<details>
<summary>Реализации</summary>

```rust
pub fn add(a: i32, b: i32) -> i32 {
    a + b
}

pub fn square(x: i32) -> i32 {
    x * x
}

pub fn volume(width: f64, height: f64, depth: f64) -> f64 {
    width * height * depth
}

pub fn average3(a: f64, b: f64, c: f64) -> f64 {
    (a + b + c) / 3.0
}

pub fn print_and_count(text: &str) -> usize {
    println!("{text}");
    text.chars().count()
}
```

Скобки в `average3` обязательны: без них разделится только `c`.

</details>

<details>
<summary>Почему `print_and_count` возвращает `usize`</summary>

`chars().count()` возвращает `usize` — тип, которым измеряют размеры. А `println!` возвращает `()`,
поэтому он идёт отдельной строкой и «выбрасывается», а значение функции даёт последняя строка.

</details>

<details>
<summary>Эксперимент</summary>

Без `;` в конце тела функция возвращает результат выражения. С `;` результат выбрасывается,
функция начинает возвращать `()` — и компилятор скажет `E0308: mismatched types`.

С `return` всё иначе: `return a + b;` — это **оператор**, и точка с запятой там обязательна как часть
синтаксиса, а не как «выбросить значение».

</details>
