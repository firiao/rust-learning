## Важные факты по окружению

- Arch Linux, `rustc 1.99.1`, edition 2024, resolver 3, **rustup нет**.
- В рабочей папке **нет git**; `rust-analyzer` не установлен (ставить только с согласия).
- Каталог `/tmp` в песочнице агента **приватный на каждый вызов** — временные файлы там не переживают
  переход между вызовами. Для экспериментов использовать `.scratch/` (в `.gitignore`).
- **`RAYON_NUM_THREADS=1` обязателен** для Candle и любых мелких тензорных вычислений в песочнице:
  иначе `gemm` создаёт потоки, и накладные расходы дают замедление до 55× (проверено: 6м42с → 7с).

## Проверенные факты по Candle 0.11.1

- loss: `candle_nn::loss::binary_cross_entropy_with_logit` — **`logit` в единственном числе**,
  принимает логиты (сам применяет sigmoid). Функции `bce` нет.
- `ParamsAdamW::default().weight_decay == 0.01` — для XOR ставить `0.0` явно.
- `VarMap::load` не создаёт переменные: сначала модель, потом `load`.
- `Device::set_seed` на CPU **не работает**: `cannot seed the CPU rng with set_seed`.
  Детерминизм в тестах — через `varmap.set_one("l1.weight", &tensor)` после создания модели.
- Имена переменных слоя: `l1.weight`, `l1.bias`, `l2.weight`, `l2.bias`.
- XOR стабильно сходится при `hidden=16, lr=0.1, weight_decay=0.0, epochs=2000` (100/100 запусков).
  `hidden=8` не сходится в 2–3% запусков (loss застревает на ≈ 0.3466); `lr=0.5` ломает обучение (2/10).
